# Visual atlas redesign · 2026-11-08

Reference: five user-provided screen photos. The information design follows the photographed cluster map, topic-row/year-axis dot timeline, three-column compact paper library, right-side reading panel and Google Scholar entry. Colors are restrained slate with six topic accents on white/light grey surfaces. The five primary screens are retained; no attached reference text was treated as instructions or imported as research evidence.

The global overview now shows counts, six research directions, recent experiments and next tasks. Each direction opens its corresponding architecture. Repetitive introductory copy and global constraint badges were removed from the main surfaces. Longer scheme explanations and sources remain available in a disclosure below each architecture. The editable tree initially folds stage branches.

The topic network positions papers deterministically within theme clusters. Only saved `relatedTo` links are drawn as paper edges; these are described as card associations, not claimed bibliographic citations. Empty topics and undated items remain explicit. The timeline uses actual stored publication years and themes, with separate rows and clickable points. Unknown years are listed below and never assigned an invented date.

The library supports text/theme/status filtering, year/title sorting, topic chips and compact previews. Reading opens an accessible native dialog aligned to the right; all five reading dimensions are shown there. Editing, upload, API drafts, source documents and notes remain supported. Scholar links encode the actual paper title; no search results or external literature were fetched during this visual change. Authors and venue fields can be filled manually without inventing existing metadata.

Validation: TypeScript and production build, existing tree/API checks, browser checks for five horizontal navigation entries, overview-to-idea-six routing, search, graph/timeline-to-reader clicks, five reading dimensions, editor fields, Scholar URL, tree edit entry and 390px library/timeline/tree page overflow. Desktop/mobile overview, graph, timeline, library and reader screenshots were inspected; an inherited column navigation rule was corrected before final packaging. Side-panel margins account for the native viewport scrollbar. Database schema, keys, source papers and sharing are unchanged.
