# 实验进度思维导图

研究推进默认显示想法三的实验树。六个想法沿用原始 node 记录及父子关系；根节点、阶段和实验通过曲线连接。初始收起较大树的阶段，点击圆钮展开，点击卡片编辑，右上角 + 在该节点下新增。

- SVG 仅绘制连线，节点使用可聚焦 HTML 按钮，保留编辑表单与 D1 持久化。
- 展开单个分支时保持点击节点的屏幕位置；支持画布拖动、方向键平移、缩放及适应视图。
- “专注画布”提供独立大画布；Escape 退出，编辑弹窗打开时优先处理弹窗。
- 状态筛选保留完整祖先路径并展开匹配节点，筛选期间禁用分支收起，避免隐藏结果。
- “已实验 / 已完成”只统计原记录的对应状态，不推断实验成功或改变验收结论。
- 根节点不能删除或选择其他父节点；编辑其他节点沿用已有同想法、无循环、父节点有效等后端校验。

布局逻辑：`lib/mindmap-layout.ts`。界面：`app/progress-mindmap.tsx` 和 `app/progress-mindmap.css`。

校验：`node scripts/check-mindmap.cjs`。覆盖节点不重叠、父子方向、分支收起、保留筛选祖先、深层节点和全部六棵实验树。浏览器另验证新增、刷新保留、删除测试节点、拖动和缩放。
