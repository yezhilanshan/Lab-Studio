# 简洁思维导图

研究推进的实验树与独立导图共用编辑器。保持原工作台的纸色和灰绿配色，顶部只放六个入口：主题、细分主题、联系、概要、外框、添加。

## 交互

- 左键在空白处拖动框选；点击主题单选，Shift 点击或 Shift 方向键多选。拖动主题移动整棵分支。在其他主题中央停留约 260 毫秒后显示挂载预览，在同级主题边缘停留可排序。松手前按 Esc 可取消。多选移动只处理最上层的所选分支，一次拖放对应一次撤销。
- 右键点击主题打开节点菜单，右键拖动空白处平移画布。滚轮平移，Ctrl 滚轮缩放。
- Space 或双击编辑主题，Enter 确认，Shift Enter 换行，Esc 取消。输入过程中 Ctrl Left / Right 移到文本首尾，Home / End 保留原生行为。中文输入候选期间可确认候选词，编辑框内的 Backspace 删除文字。
- Backspace 删除所选主题及其后代，Ctrl Backspace 只删除所选主题并提升其子主题。两种删除均可撤销，图中删除不会自动写入实验记录。删空后可点击“添加中心主题”恢复。
- 格式面板默认隐藏，Ctrl ] 开关；包含文字、字号、颜色、快捷样式与可折叠的主题记录字段。移除通用绘图形状、填充、线型等大面板。
- “添加”菜单分为内容、关联和画布操作。鼠标悬停或选中主题时，主题右上角的加号用于添加子主题。
- “添加 → 画布操作”提供导入、完整导出、SVG 导出、扩散/向右/向下自动布局，以及实验导图的双向同步。扩散布局把主节点的分支均衡分到左右两侧，节点较多时优先使用。实验树的子主题始终从父主题的左右侧边连接，只有主动选择“向下自动布局”时才从上下侧边连接。
- 一级子主题使用文献库主题色的浅底和深色文字，二级子主题使用更浅的同色系描边。连线降低不透明度，便于扫读时按分支成组。颜色取自 `catalog-topics.json` 的现有色板，随分支顺序循环；手动改过填充色或文字色的主题保留自定义样式。
- 中心主题到一级子主题保留平滑曲线；一级子主题之后的分支连线采用 XMind 式直角结构：父主题先水平出线，再沿兄弟节点共用的竖干上下移动，最后水平接入子主题，转折处为小圆角。节点较多时不再从同一点呈扇形散开；向下自动布局时方向互换。
- 新增、删除、折叠和展开时，整理受影响的分支。每组可见子主题围绕自己的父主题居中。相邻分支空间不足时，按整棵子树占位拉开同侧父主题的间距。位置锁定的主题遇到展开冲突时会随整条分支移动，可在右键菜单解锁。显式运行全局布局会重新排布所有可见分支，按每个父主题的实际尺寸计算父子间距。
- 底栏的搜索入口或 Ctrl+F 可查找标题、笔记、标签和实验编号。结果显示祖先路径，跳转后展开必要的祖先并选中目标。画布右下角可显示或隐藏小地图。完整快捷键见 [mindmap-shortcuts.md](mindmap-shortcuts.md)。

## 节点右键菜单

- 拷贝、剪切、粘贴和复制支持完整分支及其附件。粘贴文本时，可按空格或 Tab 缩进、Markdown 列表及标题生成树结构。副本使用新的节点 ID，实验记录需通过同步预览另行关联。
- “插入”包含笔记、标签、待办、任务、网页、嵌入链接、导图链接、主题链接、标注、附件、标记、贴纸、插画和图片。嵌入预览取决于目标网页的嵌入策略，也可打开原网页。
- 生成想法、工作分解、图片和解释需要填写 API 地址、模型及密钥。生成结果先预览，确认后才加入导图。图片接口须返回 `b64_json`，见 [图片生成 API 文档](https://developers.openai.com/api/reference/resources/images/methods/generate)。

## 样式与视图

样式可跨画布拷贝/粘贴；Ctrl Alt U 把选中主题样式设为当前画布新主题的默认值。用户列出的两个“极其重要”分别对应 Shift Alt 1 红色、Shift Alt 2 橙色；Shift Alt 3 为删去，Shift Alt 0 恢复默认。

“仅保留文本”切换为纯文本外观，隐藏图片及标签等附加内容但保留其数据；重设样式可恢复显示。折叠与“仅显示该分支”只控制视图，完整导出始终包含隐藏节点及图片。SVG 导出可见主题和元素。

## 实验记录同步

按上次同步快照比较标题、父节点、状态、笔记/结果、下一步和证据，预览后才应用。双方修改同一字段时逐项选择采用哪一方。预览区分新增、更新、冲突与失效关联，服务端在写回时核验记录，并在 D1 批次内检查修订版本。同步保留手工位置、样式和折叠状态。

每次成功应用都会在场景中记录快照 ID、源修订版本、变更字段及结果，保留最近 20 次。新实验补入当前画布，新主题写回后新建实验节点并关联。源记录移除时保留图中内容并标记失效关联。导图撤销只改变画布，已写回的实验记录需再次通过差异预览同步。

## 跳到历史证据

实验进度树的主题与「研究推进 → 历史证据」的节点按记录 ID 一一对应（`node-T05` ↔ `T05`，转换集中在 `lib/evidence-link.ts`）。选中主题后，右键菜单或格式面板「主题记录」里的「在历史证据中查看」会切到历史证据页签、停在「演进路线」并打开该节点详情：问题、尝试、结果与限制、下一步，以及挂接的完整分析文档和来源证据。关闭详情后列表会滚动回该节点并高亮。没有记录关联的主题（如独立画布或新建主题）不显示此入口。

反方向由历史证据节点详情里的「在实验进度树中定位」承担：按 `node-<ID>` 找到记录所属想法，切到该想法的实验进度树，展开必要祖先、选中并居中该主题（页脚提示「已定位到…」）。打开时跳过整树 fit，避免刚定位就被缩放覆盖。记录已删除或不存在时只切换到进度树，不做定位。

## 保存和代码

R2 场景保留 Excalidraw 格式，D1 记录指向已保存的场景。编辑后立即提交 IndexedDB 草稿，远端保存仍合并短时间内的连续编辑。场景最大 20MB、10000 个元素，图形、标签和连线都计入。完整文件包含节点、图片、附件和元数据，资源以 ID 引用，相同内容可复用同一份数据。普通“导出全部记录”仅备份场景索引，完整迁移请逐图导出。

- `app/mindmap-canvas.tsx`：保存、导入导出、画布切换及编辑器入口。
- `app/simple-mindmap-editor.tsx`：专用导图编辑器与已有控制器适配。
- `app/mindmap-surface.tsx`：SVG/HTML 主题显示、框选、平移、分支拖放、文字编辑。
- `app/use-mindmap-tools.ts`：命令执行、对话框、样式与快捷键分发。
- `app/mindmap-toolbar.tsx`：六项工具、添加菜单、底栏与隐藏格式面板。
- `lib/mindmap-actions.ts`：主题插入、删除、排序、样式、分组和快捷键注册表。
- `lib/structured-mindmap.ts`：关系校验、布局、折叠、移动和三方同步比较。
- `app/use-structured-mindmap.ts`：完整场景历史与实验同步；旧绘图快捷键已在新编辑器禁用。

仍使用项目内 Excalidraw 场景结构与依赖进行兼容转换；当前主界面使用专用导图交互层，不展示 Excalidraw 通用绘图工具。`vendor/excalidraw` 为官方 0.18.0 嵌入包，`vendor/excalidraw-upstream` 为用户源码的原样副本。MIT 许可与源码哈希保留；本次没有修改第三方源码，也不需要根目录 `excalidraw-master`。

## 验证

- `node node_modules/typescript/bin/tsc --noEmit --incremental false` 和 `npm run build`
- `node scripts/check-mindmap-stability.cjs` 检查局部布局、多选移动、随机编辑、搜索、大纲、附件和草稿格式。
- 本地开发服务器运行后，`node scripts/check-mindmap-browser.mjs` 使用无头 Chrome 和模拟导图，检查拖放撤销、输入法、搜索、小地图、草稿恢复、Worker 以及 SVG 导出。
- `node scripts/check-mindmap-d1.cjs` 使用隔离的 Miniflare D1 测试重试和并发冲突。
- `node scripts/benchmark-mindmap.cjs` 测量 1000、3000、10000 个合成逻辑节点的模型操作耗时，包括视口查询、移动、折叠、布局与 JSON 序列化。序列化计时不含 R2 上传和 D1 写入。

结构化主题元数据决定节点关系和排序。视图从主题和形状坐标推导可见分支，保存时同步生成 Excalidraw 兼容连线。旧文件可从连线恢复父子关系，加载时补齐结构化元数据。
