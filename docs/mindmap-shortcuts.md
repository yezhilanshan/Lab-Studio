# 思维导图快捷键

52 项操作（方向键按四个方向分别注册，共 59 个组合）。Mac 可用 Command 代替 Ctrl。输入框中保留正常输入，Space 或双击打开的主题编辑框支持文本首尾、粗体、斜体和字号快捷键。

| 操作 | 快捷键 |
|---|---|
| 搜索当前导图 | `Ctrl F` |
| 新建画布 | `Ctrl Alt N` |
| 上一张画布 | `Ctrl Alt [` |
| 下一张画布 | `Ctrl Alt ]` |
| 撤销 | `Ctrl Z` |
| 重做 | `Ctrl Shift Z` |
| 拷贝样式 | `Ctrl Alt C` |
| 粘贴样式 | `Ctrl Alt V` |
| 重设样式 | `Ctrl Alt 0` |
| 删除单个主题 | `Ctrl Backspace` |
| 删除主题及其分支 | `Backspace` 或 `Delete` |
| 拷贝分支 | `Ctrl C` |
| 剪切分支 | `Ctrl X` |
| 粘贴分支或文本 | `Ctrl V` |
| 复制分支 | `Ctrl D` |
| 细分主题 | `Tab` |
| 主题（之后） | `Enter` |
| 主题（之前） | `Shift Enter` |
| 上级主题 | `Ctrl Enter` |
| 联系 | `Ctrl Shift R` |
| 外框 | `Ctrl Shift B` |
| 标签 | `Ctrl Shift L` |
| 图片 | `Ctrl Shift I` |
| 超链接 | `Ctrl K` |
| 评论 | `C` |
| 专区 | `Ctrl Alt Z` |
| 仅保留文本 | `Ctrl Shift -` |
| 编辑主题文本 | `Space` |
| 移动到文本起始 | `Ctrl Left` |
| 移动到文本末尾 | `Ctrl Right` |
| 粗体 | `Ctrl B` |
| 斜体 | `Ctrl I` |
| 加大字体 | `Ctrl Shift .` |
| 减小字体 | `Ctrl Shift ,` |
| 极其重要 · 红色 | `Shift Alt 1` |
| 极其重要 · 橙色 | `Shift Alt 2` |
| 删去 | `Shift Alt 3` |
| 默认 | `Shift Alt 0` |
| 更新默认样式 | `Ctrl Alt U` |
| 前往中心主题 | `Ctrl R` |
| 移动选择框 | `Arrow` |
| 多选主题 | `Shift Arrow` |
| 主题上移 | `Alt Up` |
| 主题下移 | `Alt Down` |
| 移动主题到顶部 | `Ctrl Alt Up` |
| 移动主题到底部 | `Ctrl Alt Down` |
| 折叠/展开细分主题 | `Ctrl /` |
| 折叠/展开子分支 | `Ctrl Alt /` |
| 仅显示该分支 | `Ctrl ;` |
| 放大 | `Ctrl =` |
| 缩小 | `Ctrl -` |
| 实际尺寸 | `Ctrl 0` |
| 显示/隐藏格式面板 | `Ctrl ]` |

左键框选。右键点主题打开菜单，拖动空白处平移。Esc 关闭菜单、取消联系或退出分支视图。两种“极其重要”按用户列表分别设置为红色、橙色。
