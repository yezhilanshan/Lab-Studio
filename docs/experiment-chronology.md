# 实验编年线（2026-11-11）

「研究推进 → 历史证据」原先分成两个页签：按阶段归拢的演进路线，和按类型检索的 232 份完整分析。两者描述同一批工作，但读者要在两个视图之间来回对照。现在合并为一个面：一条按日期排列的实验编年线，每一步就地挂着它的原文与来源证据。

## 排序与日期

- 顺序取自记录本身（`research-data.json` 的 73 个节点），按日期升序排；序号 `01/73` 直接显示在卡片左上，便于说明"这是第几步"。
- 日期优先级：`app/research-chronology.ts` 的 `recordDates`（正文或运行记录核验过的日期）→ 挂接文档的日期 → 源文件名里的 `YYYY-MM-DD` → `undatedPositions`（只知道相对位置、没有确切日期的少数节点）。三者都没有的进入「早期设计 · 日期未详」，排在最前，不猜日期。
- `recordDates` 里一条记录可有起止两天（`2026-10-03/2026-10-04`），卡片显示为「至」区间。

## 因果怎么表达

- 每张卡片固定四段：**为什么做**（problem）、**怎么做**（attempt）、**结果与限制**（result）、**为什么转向下一步**（next）。
- 「后续记录」只来自 `followUps`：只有实验记录本身写明"下一步做 X"时才连线。列表里相邻的两条记录可能属于互不相关的实验，所以没有连线时会显示「记录没有指明紧接着的下一步；相邻条目按日期排列，不代表属于同一实验」。
- 每条后续记录下面附上目标的 **problem**（「它要解决的问题」），这样不点进去也能看出"为什么要换成那个实验"。
- 反向由 `followUps` 生成 `PRECEDED_BY`，目标卡片标题下出现「↳ 承自 T06 · … 的下一步」，可点击回跳。正反两侧合起来就是一条连续的因果链。

## 证据

- 每一步的「原文与证据」折叠区列出挂接的完整分析（Markdown 全文、表格、图片）与其他来源（S0xx/V0xx，含本地路径）。从实验进度树跳转过来时会自动展开。
- 展开后的正文使用卡片整宽：`在实验进度树中定位` 放在标题行右侧（不在 footer 占位），证据块不再被挤成窄栏；`node-doc-details` 的左右内边距归零，正文与卡片标题对齐。
- 宽表在记录内按 `table-layout: fixed` 均分卡片宽度，表头允许换行、数值 `nowrap`，保证数字不被折断；列数更多的表退回 `overflow-x: auto` 横向滚动。
- 没有挂到任何节点的 147 份文档收在页尾「补充文档」，保持可检索、可按类型筛选；**不做按日期或标题的自动挂接**，避免把"看起来相关"当成"记录中的关联"。

## 交互

- 顶部月份导航按章节跳转；搜索同时匹配节点字段、挂接文档标题/摘要/章节与来源标题。
- 「在实验进度树中定位」把当前记录反查回它所属的想法，切到进度树并选中该主题。
- 滚动定位统一留出固定顶栏的高度（`scroll-margin-top: 88px`），避免标题被压住。

## 右侧路线栏

视口 ≥1180px 时，正文右侧常驻一条 288px 的索引栏，把宽屏的空白用起来：

- **研究路线**：步数、阶段数、后续连线数、记录跨度；下方一个「补充文档 147」入口，直接展开页尾的未挂接文档。
- **阶段**：11 个阶段带条目计数，点击即筛选（再点或点「显示全部」还原）；当前筛选项以左侧竖条标出。
- 滚动时用 `requestAnimationFrame` 读 `.experiment-record[data-group]` 的位置，把当前所在阶段高亮，并在下方显示该阶段的结论（`group.conclusion`）——读者随时知道自己处在 73 步的哪一段。
- **读法**：解释「已实验 / 设计·实现 / 终态未核实」的区别与日期来源，避免把设计记录误读成验收结论。
- 窄屏（<1180px）整栏隐藏，功能回落为工具栏的阶段下拉与「补充文档」按钮。

## 样式与测试

- 样式在 `app/desk.css` 的 `.atlas-shell` 作用域内（`.experiment-*`），沿用纸面配色：卡片 1px 细边、左侧时间轴与圆点、四段用细线分隔。注意 `nav` 有全局 `flex-direction: column`，月份导航需显式 `row`。
- `scratch/check-chronicle.mjs`（链接、搜索、补充文档、反查、移动端溢出）、`scratch/check-evidence-jump.mjs`（树 → 证据）、`scratch/check-locate-in-tree.mjs`（证据 → 树）覆盖主要路径。
