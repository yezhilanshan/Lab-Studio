这三层的采集目标完全不同：**第 1 层要"纯"，第 2 层要"密"，第 3 层要"真"**。对应的采集形式也不同——孤立短动作、过渡动作、完整事件链。

---

## 总览：三层采集逻辑

| 层        | 采集形式                | 单次时长   | 核心目的                       | 供给                         |
| -------- | ------------------- | ------ | -------------------------- | -------------------------- |
| 第 1 层 原语 | 孤立采集（一次只做一个动作）      | 3~60s  | 获得干净的单动作样本，学会动作的基本语义       | Stage 1 辅助监督、单事件标签         |
| 第 2 层 过渡 | 过渡专项 take（稳态→过渡→稳态） | 8~15s  | 学习相似动作的转换过程                | 边界学习、Transition Latency 评估 |
| 第 3 层 场景 | 完整事件链自然表演           | 30~90s | 让模型学会区分自然场景下的动作切换并输出自然语言描述 | Stage 2 单事件文本、Stage 4 摘要   |

注意两个"复用"：第 2 层 take 的前置/后置稳态段可以免费产出第 1 层的稳态样本；第 3 层场景里天然包含过渡，与第 2 层的"受控过渡"形成**自然 vs 诱导**的对照，分析时很有用。

## 第 2 层：过渡采集清单

这是你方法的命门，也是现有毫米波数据集普遍缺的东西。采集形式统一为**过渡动作片段**：

```
前置稳态 2~3s → 过渡 → 后置稳态 2~3s   （一个 take 8~15s，只含一个过渡）
```

### 过渡清单（约 20 类）

| 组       | 过渡                                           | 时长  | 说明                |
| ------- | -------------------------------------------- | --- | ----------------- |
| A 姿态-姿态 | 站→坐、坐→站、站→弯腰→站、弯腰→下蹲、蹲→站、坐→躺、躺→坐、            |     | 高度变化明显            |
| B 静止-运动 | 站立静止→起步（向前/向侧）、行走→急停、坐→起身即走（无中间停顿）           |     | 边界测试              |
| C 速度调制  | 慢走→快走、快走→慢走                                  |     | 类别不变，但是动作模式发生变化   |
| D 交互触发  | 伸手→拿起、持物→放下、拉门→松手、弯腰→捡东西、拿起水壶→倒水、扔东西、打电话、搬东西 |     | 人-物的交互动作，帮助模型理解环境 |
| E 异常    | 行走→踉跄→恢复、行走→失衡→扶物支撑                          |     | 持续时间短，但是动作变化剧烈    |

依然可以考虑人与雷达相距不同距离、朝向，但是考虑到每个动作同一个人都要重复很多次，数据规模可能过大

- 每人每条件：20 类 × 5 take × ~12s ≈ **20 分钟**；
- 产出约 100 个带区间标注的过渡样本/人/条件，15 人仅主条件就有 ~1500 个密集边界样本——这是任何场景采集都给不了的密度。

## 汇总与分配

| 层 | 单条件耗时 | 条件 1（主） | 条件 2、3 | 条件 4 |
|---|---|---|---|---|
| 1 原语 | ~30 min | 全量 | 全量 | 1/2 轮换 |
| 2 过渡 | ~20 min | 全量 | 全量 | 1/2 轮换 |
| 3 场景 | ~50 min | 全量 | 核心 16 条 | 1/2 轮换 |
| 负样本/Idle | ~15 min | 全量 | 全量 | 全量（便宜且重要） |
| **合计** | **~2h** | | | |

每人每条件约 2 小时，拆成两次采集（中间隔天）防疲劳——疲劳会直接影响第 2 层过渡的自然度，这是不能省的。

最后一个设计要点：三层的标注成本不同。**第 1 层**只要单标签，成本最低；**第 2 层**要标过渡区间 [t₁,t₂]，单位成本最高，但它 take 短、量可控；**第 3 层**走完整文本管线。所以采集顺序建议按层推进：先采第 1、2 层并跑通区间标注流程（试点阶段重点验证这个），再开始第 3 层的大规模采集——否则你会发现场景采了一堆，标注管线还没跑通。
