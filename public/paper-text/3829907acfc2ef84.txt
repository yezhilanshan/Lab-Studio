01 先看结论：近两年长视频处理的 8 条主线
长视频研究的核心矛盾已经从“模型能不能接收更多帧”，转向“如何在有限预算下持续找到、压缩、保留和组织真
正有用的证据”。近两年的代表方法大致可以归为以下八类。
1 关键帧 / 自适应采样 先决定“看哪里”，再做推理。2026 年明显从启发式相似度转向 RL、置信度与
问题粒度驱动。
2 视觉 Token / 层级压缩 先在时间维删冗余，再在帧内压缩；逐渐出现可变压缩率与“重要事件多给
Token”。
3 Memory / Streaming 把短期高保真上下文与长期压缩记忆分离，并加入写入、合并、淘汰和回看机
制。
4 RAG / 结构化检索 从扁平向量检索走向事件图、多跳检索和 intent-aware retrieval。
5 Agent / Tool Use 模型主动决定下一步看哪个片段、是否放大、是否继续搜索，以及何时停止。
6 层级 / 事件结构 frame clip/event video
→ → 的树或图，逐渐成为长视频信息组织的通用骨架。
7 时序定位 / 在线充分性 不仅回答“发生了什么”，还判断“什么时候发生”“什么时候已经有足够证
据回答”。
8 数据 / Benchmark 开始专门构造小时级训练数据、极长视频 Benchmark 和关键时刻检索
Benchmark。

01 DrVideo: Document Retrieval Based Long Video Understanding
CVPR 2025 方法 检索/RAG ★★★★★
论文概述｜把长视频先转化为可检索的“视频文档”，再围绕问题定位相关片段并进行跨片段推理，核心目
标是绕开把整段视频一次性塞进多模态模型的上下文与计算瓶颈。
可借鉴点｜很适合作为“先结构化、再检索、后推理”的基线思路。对任意长时序信号，都可以先生成分段
摘要/事件文档，再用问题驱动检索缩小推理范围。

02 M-LLM Based Video Frame Selection for Efficient Video Understanding
CVPR 2025 方法 关键帧/采样 ★★★★★
论文概述｜针对均匀采样容易漏掉关键证据的问题，用多模态大模型本身参与帧选择，让采样更贴合问题语

可借鉴点｜最直接的启发是把“采样”从固定预处理变成任务相关模块。若长序列中信息密度不均，可先学

08 VideoTree: Adaptive Tree-based Video Representation for LLM Reasoning
on Long Videos
CVPR 2025 方法 层级/事件结构 ★★★★★
论文概述｜构建问题自适应的层级视频树，先粗粒度判断哪些时间段值得看，再逐步向下展开到更细的关键

可借鉴点｜树状多粒度组织非常适合长时序：全局节点保存摘要，子节点保存事件，叶节点保存细节。可以
避免固定粒度切分导致“要么太粗、要么太贵”。

15 LongVU: Spatiotemporal Adaptive Compression for Long Video-Language
Understanding
ICML 2025 方法 Token 压缩 ★★★★★
论文概述｜从时间和空间两级做自适应压缩：先删除高冗余帧，再根据文本问题保留更相关的帧特征，同时
继续压缩单帧内部视觉 Token。
可借鉴点｜这是“多级压缩”的代表作：长时序系统可以先做时间级筛选，再做事件/局部特征级压缩，比单
一 Tokenizer 更容易控制信息损失与算力。

06 横向对比：真正值得带走的设计模式
A. “先事件化，再压缩”优于直接压整段
长序列先形成 clip/event 单元，再在事件层做摘要、检索或记忆；可显著降低对逐帧表示的依赖。
代表论文：VideoTree / SALOVA / StreamForest / VideoChat-Flash
B. 固定 Token 数正在让位于动态预算
信息密集事件多分配 Token，静态或重复片段少分配；问题难度和时间粒度也可参与预算分配。
代表论文：B-VLLM / LangDC / ReQuest / ReMem
C. Memory 正从“缓存”变成“可操作的数据结构”
长期记忆开始具备分层、合并、索引、回看和多类型存储能力；事件树/异构 Memory 是明显趋势。
代表论文：ReWind / Flash-VStream / StreamForest / WorldMM
D. Agent 的核心不是“LLM 套工具”，而是证据闭环
每一步都要回答：当前证据缺什么？下一步去哪里找？是否已经足够？训练目标也从最终答案扩展到搜索轨迹。
代表论文：VCA / DVD / LongVideo-R1 / TimeSearch-R / Video-o3
E. 时序定位应该成为独立训练与评测目标
只评最终文本会掩盖“没找对时间却答对”的问题。最好同时评事件边界、关键时刻、先后关系和最终生成。
代表论文：TimeSuite / MomentSeeker / TEMPLE / Progressive Online
F. 物理/运动先验仍然有价值
低层运动信息可以在进入大模型前帮助剔除冗余；这条路线尤其适合视觉之外的时序传感器。
代表论文：Flow4Agent
07 如果只想快速建立长视频研究框架
1. 先读 VideoTree + SALOVA：理解为什么要从逐帧处理升级为事件/层级结构。
2. 再读 LongVU + VideoChat-Flash：理解时间压缩、空间压缩和层级压缩怎么组合。
3. 再读 ReWind + StreamForest + WorldMM：理解长期 Memory 如何从缓存升级为事件化、异构、可检索结构。
4. 再读 VCA + LongVideo-R1 + TimeSearch-R + Video-o3：理解 Agent 如何主动搜索、补证据和决定停止。
5. 最后看 MLVU + LVBench + MomentSeeker：设计自己的长时序实验时，把“长度、检索、定位、推理”分开评估。
