01
长序列 SNN 与 State Space Model
本组是本届最值得重点追踪的算法方向：把 SNN 与 State Space Model 的线性/选择性状态更新结合，试图同时改善长依
赖、并行训练和事件稀疏性。 本节 2 篇
S
01
Phase State Space Models: Parallel, Surrogate-Free Training of Spiking Networks.
官方日程 + 题目/元数据 原文 · 公开入口
论文概述 这篇论文直接针对 SNN 训练的两个核心痛点：时间维难并行、spike 不可导导致依赖 surrogate gradient。作者提出 Phase State
Space Models，目标是在状态空间结构中实现并行、surrogate-free 的 SNN 训练。当前可检索公开内容以会议元数据为主，定量结果需以
正式论文为准。
可借鉴点 这是本届最值得追的一条主线：SSM 天生适合长序列，如果还能绕开 BPTT/替代梯度，可能同时解决“学不动”和“记不
久”。；对长时间毫米波动作描述，可考虑用相位/状态变量承载长程动态，而不是把 60 帧甚至更长序列全部交给 Transformer
attention。
S
02
4SM: Selective Spiking State Space Models for Neuromorphic Sequence Learning.
官方日程 + 题目/元数据 原文 · 公开入口
论文概述 4SM（Selective Spiking State Space Models）明确把 selective SSM 与脉冲序列学习结合。它与 Mamba/选择性状态更新同属
“让输入决定哪些状态需要保留/更新”的范式，特别适合长序列中大量无关时间步的场景。当前公开检索尚未获得稳定完整摘要，具体结
构应以论文正文为准。
可借鉴点 这是最接近“长时动作 + SNN”的论文之一：用选择性状态更新替代全局 attention，天然适合只在关键动作变化时写入状
态。；可以和无线信号结合：由 motion saliency/信道变化程度控制 SSM update gate，静止帧少更新、关键动作帧强更新。
可以直接转成研究问题
01 把 motion saliency / 信道变化幅度作为 SSM update gate：静止段少更新，关键动作段强更新。
02 比较 Transformer、Mamba/SSM 与 Spiking SSM 在分钟级无线序列上的记忆长度、吞吐与能耗。
03 把“相位/状态变量”解释为动作阶段记忆，而不是让每个时间步都生成独立 Token。
04 重点验证 surrogate-free / parallel training 是否真的降低长序列训练成本，而不只改变神经元形式。

02
感知前端与无线/边缘感知
本组最容易迁移到毫米波、WiFi 与多传感器感知：核心共同点是从“输入已固定”转向“采样、触发、稀疏重建、物理优

S
03
A Neuromorphic Trigger for Efficient Audio Event Detection.
公开摘要 原文 · 公开入口
论文概述 这篇论文把 SNN 放在音频处理链最前面，充当“是否值得继续算”的触发器：只有检测到显著事件时才调用更昂贵的后端模型。公开摘要
中，在 URBAN-SED 异常声音场景 F1 达到 0.97；在 DCASE 2017 设置中估计可将后端 FLOPs 降低约 42.6 倍。
可借鉴点 对毫米波/WiFi 感知非常可迁移：先用超轻量事件模型判断“当前窗口是否有动作/变化”，再唤醒大模型、Transformer 或 LLM。；
它优化的不是单个模型，而是整条感知 pipeline 的平均计算量；这种“trigger → heavy model”的系统创新通常比单纯换 backbone 更有研
究价值。
S
04
Sensor–Algorithm Co-Design for Spectral Sampling in Neuromorphic Vision.
官方日程 + 题目/元数据 原文 · 公开入口
论文概述 论文把神经形态视觉的频谱采样与下游算法作为一个整体设计，而不是先固定传感器、再被动适配模型。重点是让采样位置/方式直接服务
于任务性能与稀疏计算需求。当前可稳定公开获取的信息以会议题目和作者元数据为主，因此这里不引入未公开的定量结果。
可借鉴点 可直接迁移到毫米波：不要固定“3D FFT 后点云/热图”作为唯一输入，而是研究哪些 range-Doppler-angle 单元值得采样、何时采
样，并让采样策略受下游任务监督。；很适合形成“传感器/物理采样 + Token 化 + SNN/SSM”的协同优化课题，而不是只在网络结构上做增
量改动。
A
05
Challenging the Spatiotemporal Processing of Neuromorphic Models through a Temporally-Rich Event-Based
Dataset.
官方日程 + 题目/元数据 原文 · 公开入口
论文概述 这项工作构建时间结构更丰富的事件数据集，目标是挑战神经形态模型真正的时空处理能力。它提醒一个常被忽略的问题：很多 event/
SNN benchmark 虽然输入是事件，但类别仍可由静态轮廓或短期线索解决，因而不能证明模型学到了长时间动态。
可借鉴点 如果研究“更长时间、更细粒度动作描述”，数据集必须主动去除静态捷径，增加动作顺序、速度变化、停顿和相似动作细节等时间
判别因素。；可以借鉴其 benchmark 思维：先设计真正要求时间理解的任务，再证明 SNN/SSM 的长时序优势。
S
06
Neuroscience Inspired Graph Operators Towards Edge-Deployable Virtual Sensing for Irregular Geometries.
公开摘要 原文 · 公开入口
论文概述 论文提出 Variable Spiking Graph Neural Operator（VS-GNO），把谱-空间图卷积、Variable Spiking Neuron 和能量-误差平衡损失结
合，用少量传感器恢复不规则几何上的完整物理场。公开摘要报告：非脉冲基线 L2 误差约 0.4%；仅谱域脉冲版本误差约 0.71%、平均脉冲率约
15%，完整脉冲版本误差约 1.04%、脉冲率约 24.5%。
可借鉴点 这是“稀疏传感 → 稠密场重建 → 边缘部署”的完整模板，和无线感知中稀疏阵列/有限天线恢复空间运动场高度同构。；Variable
Spiking Neuron + energy-error loss 值得重点看：它不是只追准确率，而是显式把 spike rate/能耗纳入学习目标。

07
Direction-of-Arrival Estimation via Spiking Locally Competitive Algorithm.
官方日程 + 领域背景 原文 · 公开入口
论文概述 论文把 Spiking Locally Competitive Algorithm（LCA）用于阵列信号的 Direction-of-Arrival 估计。LCA 本质上适合以竞争动力学求解稀
疏表示/稀疏优化，因此这一工作提供了“经典阵列信号处理问题 → 脉冲稀疏优化网络”的直接映射。
可借鉴点 与你的无线方向最直接相关：DOA/角度域本来就具有稀疏结构，可以尝试在 angle/range-Doppler-angle 域用事件竞争机制替代部
分 FFT/迭代稀疏求解。；重点不是照搬 LCA，而是借鉴“把物理先验写进网络动力学”，让 SNN 不是黑盒分类器。

本组围绕在线适应与记忆稳定性，适合思考 SNN 的“记不久”：哪些信息应写入、如何用少量原型保存旧知识、何时通过

08
Sleep-Inspired Replay-Driven Online Temporal Learning with Memristive Neuromorphic Hardware for
Edge Systems.
DBLP + 题目/公开元数据 原文 · 公开入口
论文概述 论文以“睡眠重放”作为在线时序学习的核心机制，把在线阶段获取的时序经验通过 replay/consolidation 再利用，并明确面向
忆阻器神经形态硬件和 edge systems。DBLP 已确认其为 ICONS 2026 论文；当前公开页面未稳定提供完整摘要，因此不写入未核验指标。
可借鉴点 和“记不久”的 SNN 问题直接相关：把快速在线适应与离线/低负载阶段的记忆重放分开，可能比单一在线梯度更新更稳
定。；可以迁移到无线行为识别：设备白天在线积累少量 prototype/关键片段，空闲期 replay，持续适应新用户/新环境。
S
09
Prototype Replay for Cold-Start Online Class-Incremental Learning in Spiking Networks.
官方日程 + 题目/元数据 原文 · 公开入口
论文概述 面向“从随机/弱初始化开始”的 cold-start 在线类增量 SNN，论文使用 prototype replay 维持旧类知识。与保存大量历史样本相
比，prototype memory 更适合存储受限的端侧系统，同时能够在新类别持续到来时缓解灾难性遗忘。
可借鉴点 对无线感知的用户/动作增量非常实用：保存每类少量 prototype，而不是原始雷达/CSI 序列，兼顾隐私、存储和持续适应。；
可进一步和神经形态 replay、超维记忆结合，形成“短时事件记忆 → 类原型 → 长期巩固”的多层记忆系统。

10
SRMU: Relevance-Gated Updates for Streaming Hyperdimensional Memories.
公开摘要 原文 · 公开入口
论文概述 SRMU 面向流式 Hyperdimensional Memory，引入 relevance gating 和 temporal decay：只有与当前记忆真正相关的信息才更
新，同时逐渐衰减旧信息。公开摘要报告，相比基线可提高约 12.6% memory similarity，并降低约 53.5% 累积记忆幅度。
可借鉴点 “在意才写入”与注意/主动感知的生物启发非常接近：不是所有输入都更新状态，而是由相关性门决定是否形成记忆。；可
以直接改造成 SNN 的 relevance-gated membrane/synaptic update，减少无意义 spike 与长期状态污染。
