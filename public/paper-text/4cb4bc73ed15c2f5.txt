ACL 2026 的 6 个方法趋势
把 52 篇论文放在一起看，最值得关注的是方法论正在发生的这些变化。
01
非文本信号进入 LLM，不再只靠 Projector
越来越多工作把“数值/音频/脑信号”先变成可验证证据、结
构图、成熟表征或检索知识，再交给 LLM。
02
多模态对齐从“统一空间”走向“路由 + 结构约
束”
UniversalRAG、Text Space as Anchor 等都在质疑“一股脑
共享 embedding 空间”。
03
RL 开始优化“过程与计算路径”
不仅奖励最终答案，还优化去噪轨迹、工具调用次数、空间信
息贡献、熵变化和自我批判。
04
长上下文优化进入 KV/Attention/Speculation
协同设计
Token 压缩只是一个环节，越来越多论文同时考虑位置、缓
存、验证、硬件内核。
05
Agent Memory 从向量库变成“可操作、可治理
的状态系统”
Memory-R1、MAGMA、Text2Mem 都强调写入、更新、因
果/时间结构和执行语义。
06
解释性开始要求“可复现 + 可因果干预”
不再满足于热力图；SAE 一致性、path patching、表征轨迹
都强调可验证机制。

01
Is EEG-to-Text Feasible in Real-World Scenarios? An In-Depth Analysis Using a
Neuropsychology-Inspired Benchmark
ACL Long
论文概述 论文重新审视 EEG-to-Text 的真实可行性，指出以往评估容易受到 teacher forcing 等设置影响，并通
过神经心理学启发的基准更严格地考察脑电信号在不稳定、跨场景条件下是否仍能支持文本解码。核心价值不只
是提出模型，而是把“信号究竟贡献了多少语义”这一问题单独拆出来验证。
可借鉴点 非常适合借鉴到毫米波/WiFi→文本：先设计“去掉信号后性能是否仍然成立”的反事实基准，避免语
言模型绕过物理模态。
原文 https://aclanthology.org/2026.acl-long.61/

02
Inferring Events from Time Series using Language Models
ACL Long
论文概述 研究让语言模型根据时间序列推断其背后未显式给出的自然语言事件，并构造自动化任务生成与评测流
程。对 18 个 LLM 的实验表明，即便上下文很少，模型也能从数值动态中恢复部分事件语义；进一步结合知识蒸
馏与强化学习，小模型可以逼近大型专有推理模型。
可借鉴点 这是“传感器序列→事件描述”的直接范式：可把无线时序先转成结构化数值特征，再训练模型恢复动
作/场景事件。
原文 https://aclanthology.org/2026.acl-long.157/

ZARA: Training-Free Motion Time-Series Reasoning via Evidence-Grounded LLM Agents
ACL Long

放集活动识别，并表现出跨被试、跨数据集迁移能力。
可借鉴点 与无线感知高度同构：把“物理特征→可验证自然语言先验→检索→LLM 推理”作为替代纯 Projector
的路线。

RespiraMFM: A Multimodal Foundation Model with Contrastive Audio-Language Alignment

ACL Long

06
emg2speech: synthesizing speech from electromyography using self-supervised speech

ACL Long
论文概述 论文把口面部肌电 EMG 映射到自监督语音模型的表征空间，再从该空间合成语音。作者发现自监督语

可借鉴点 可尝试把毫米波/CSI 对齐到已有视频、动作或文本模型的中间表征空间，利用成熟语义空间降低新模

07
Language Reconstruction with Brain Predictive Coding from fMRI Data
ACL Long

MoCa: Modality-aware Continual Pre-training Makes Better Bidirectional Multimodal

ACL Long
论文概述 MoCa 将因果 VLM 改造成更适合检索/Embedding 的双向多模态模型。第一阶段用图文交错数据做联合

10
EMCompress: Video-LLMs with Endomorphic Multimodal Compression
Findings
论文概述 EMCompress 把长视频压缩形式化为“保持答案不变的充分统计量”问题：不是把视频压成不可解释
latent，而是把原始视频与问题压缩成仍处于原任务空间中的更短视频/问题表示，再交给任意下游模型推理。这

可借鉴点 可迁移为“物理 Token 的任务保持压缩”：要求压缩前后对动作描述/问答的答案不变，比单纯最小化
重建误差更贴近下游目标。

物理证据文本化 + LLM 推理

时空图 + RL 奖励

任务保持的 Token 压缩

文本空间作为锚点

05
并行候选 + 串行验证
Diffuse Thinking × CURE：并行产生多个物理解释，再用自
批判/验证策略收敛到可信结论。

动态计算轨迹
