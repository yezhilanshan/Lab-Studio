INFOCOM 2026 的 8 个方法趋势
把本次筛出的论文放在一起看，最值得关注的不是某一个 backbone “
，而是 感知语义、物理先验、跨域泛化、
”
边缘系统与可信部署 开始被联合设计。
01
无线感知从活动标签走向细粒度语义
mmWave 语音、多人“谁说了什么”和 RaECG 表明，无线信号正
在承载更丰富、更细粒度的语义目标。
02
多模态开始专门修正主模态的结构性缺陷
DuTrack 用声学锚点修正 Wi-Fi 长时漂移；毫米波语音则用 RF 信
息约束声学增强与分离。
03
物理几何重新进入 Token / Attention
GAI-NeRF、RadCloudSplat 不把信道当普通序列，而是把几何、
散射体和传播场写入表示。
04
跨环境泛化转向“不变量 + 在线适应”
PicoTag、ChannelMAE 与 Domain Generalization 分别从不变
量、自监督适应和风格统计处理域变化。
05
从单任务模型走向统一感知接口
UNI-FI 将定位、活动识别、存在检测放入统一框架，接近无线基础
模型的任务共享思路。
06
Spiking / LLM 的效率问题进入系统层
TPipe、EdgeSpec、KV Cache、BROS 说明真正瓶颈来自时间并
行、缓存、调度和请求异质性，而不只是参数量。
07
Agent / MoE 路由开始同时感知语义与资源
PPAI 与 Monic 把“谁来执行”变成动态决策，可扩展到多传感器
专家与端边云协同。
08
安全、隐私与漂移成为一等研究问题
胸振伪造、CloakFi、Drift Management、SIA 都在回答模型上线
后何时失效、为何失效以及如何限制信息泄露。

01
Who Speaks What from Afar: Eavesdropping In-Person Conversations via mmWave
Sensing
MAIN CONFERENCE · mmWave / speech / fine-grained sensing / unsupervised
原文 https://doi.org/10.1109/INFOCOM59046.2026.11571410
论文概述 面向多人面对面谈话，论文研究如何利用室外毫米波雷达捕捉物体上的微弱语音诱导振动，并进一
步回答“谁说了什么”。核心思路是利用不同说话者空间位置造成的振动差异，以无监督方式区分参与者，同
时融合多个物体的振动信号增强语音质量。
可借鉴点 非常适合借鉴“弱物理信号 -> 细粒度语义”的路线。尤其值得看：如何把空间多样性转化为说话人可
分性，以及如何在没有人数、身份、座位等先验时完成表示学习。
S
02
mmWave-Aided Unified Speech Enhancement and Separation without Speaker Count
Prior
MAIN CONFERENCE · mmWave / speech separation / multimodal
原文 https://doi.org/10.1109/INFOCOM59046.2026.11571653
论文概述 将毫米波感知作为声学语音处理的辅助信息，在同一框架中处理语音增强与多说话人分离，并去除
对“说话人数已知”这一强先验的依赖。它代表了无线感知从简单动作分类继续向复杂、开放式语音场景迈
进。
可借鉴点 如果目标是让无线信号承载更丰富语义，这篇应重点关注其“无线侧信息如何约束声学分离”的接口
设计。可迁移到雷达/视觉、雷达/语言等跨模态辅助学习。
S
03
DuTrack: Long-Term Indoor Human Tracking with Dual-Channel Sensing and Inference
MAIN CONFERENCE · Wi-Fi / acoustic / long-term tracking / physics-guided
原文 https://doi.org/10.1109/INFOCOM59046.2026.11571540
论文概述 针对 Wi-Fi 速度积分式追踪会随时间累积误差的问题，DuTrack 引入家庭中普遍存在的声学信号进
行校正。论文从电磁波 Fresnel 区与声学双曲感知区出发建立融合模型，再用数据驱动架构求解，显著降低长
时间追踪误差。
可借鉴点 重要思想不是简单“多模态融合”，而是让另一种物理模态专门修正主模态的结构性误差。对长时序
动作理解、漂移纠正、多传感器互补非常有启发。
S
04
UNI-FI: Integrated Multi-Task Wi-Fi Sensing
MAIN CONFERENCE · Wi-Fi sensing / multi-task / unified representation
原文 https://doi.org/10.1109/INFOCOM59046.2026.11571715
论文概述 提出可扩展的多任务 Wi-Fi 感知框架，试图抽象定位、行为识别、存在检测等任务之间共享的基本
结构，并自动生成多任务求解器。实验同时覆盖定位、活动分类和存在检测。
可借鉴点 很值得关注“统一表征 + 多任务求解器”的抽象方式。相比为每个任务单独训练模型，这种设计更接
近无线感知基础模型应具备的任务共享能力。
S
05
Spectrum Shortage for Radio Sensing? Leveraging Ambient 5G Signals for Human
Activity Detection
MAIN CONFERENCE · 5G / ambient sensing / ISAC / activity recognition
原文 https://doi.org/10.1109/INFOCOM59046.2026.11571246
论文概述 提出 Ambient Radio Sensing，直接复用环境中已有的 5G/Wi-Fi 通信信号做感知，而不是额外占用
专用感知频谱。系统被设计成独立设备，接收并重新利用环境射频信号，再从反射中提取人体活动信息。
可借鉴点 值得借鉴其“复用现有通信波形”的系统思维：研究重点从设计理想波形转向适应真实、异构、不可
控的环境信号，可提高感知方案的部署现实性。

06
RaECG: mmWave Radar-based Electrocardiogram Monitoring Using Chest Vibration and
Carotid Pulse
MAIN CONFERENCE · mmWave / vital signs / micro-motion / healthcare
原文 https://doi.org/10.1109/INFOCOM59046.2026.11571601
论文概述 研究利用毫米波雷达同时捕捉胸部细微振动与颈动脉脉动，以非接触方式恢复与心电活动相关的信
息。它把毫米波感知推进到幅度极弱、节律精细的生理信号层级。
可借鉴点 适合学习如何从强呼吸/体动背景中提取极弱周期信号，以及如何融合两个具有生理关联但观测机制不
同的物理源。

07
Attacking mmWave-enabled Chest Vibration Sensing via Actuator-induced Mimicry
MAIN CONFERENCE · mmWave / security / spoofing / robustness
原文 https://doi.org/10.1109/INFOCOM59046.2026.11571691
论文概述 从攻击者视角研究毫米波胸部振动感知的脆弱性：通过执行器制造与真实生理/胸振信号相似的机械
振动，诱导雷达系统产生错误判断。论文揭示“感知到运动”并不等于“理解到真实人体来源”。
可借鉴点 非常适合作为鲁棒感知的反例阅读。后续做无线大模型时，可把“物理来源一致性”“跨部位一致
性”“难伪造特征”设计成训练约束。
A
08
WiLoc: Massive Measured Dataset of Wi-Fi Channel State Information with Application to
Machine-Learning Based Localization
MAIN CONFERENCE · Wi-Fi CSI / dataset / localization / transfer learning
原文 https://doi.org/10.1109/INFOCOM59046.2026.11571288
论文概述 构建大规模实测 Wi-Fi CSI 定位数据资源，并系统研究机器学习定位及跨环境迁移问题。其价值不仅
在模型，而在于真实建筑/街区数据带来的分布差异与泛化评测。
可借鉴点 如果要验证“无线基础模型是否真的泛化”，这类大规模真实 CSI 数据集比单实验室小数据更有参考
价值。重点看数据划分、跨场景测试和迁移学习设置。

09
PicoTag: Enabling Generalized and Robust RF-Insensitive Sensing on COTS RFID Tags
MAIN CONFERENCE · RFID / generalization / invariant representation
原文 https://doi.org/10.1109/INFOCOM59046.2026.11571252
论文概述 目标是在商用 RFID 标签上实现对射频传播变化不敏感、可跨环境泛化的感知。论文把“目标物理变
化”和“RF 信道变化”之间的耦合视为核心障碍，强调从感知机理与表示层面提升稳定性。
可借鉴点 和无线感知泛化问题高度一致：可以重点学习如何构造 RF-insensitive 特征，以及如何把环境变量从
目标变量中分离。

10
RF-Gaussmeter: Noninvasive μT-level Magnetic Field Sensing using TMR-based RFID Tag
MAIN CONFERENCE · RFID / magnetic sensing / hardware-system co-design
原文 https://doi.org/10.1109/INFOCOM59046.2026.11571735
论文概述 把 TMR 磁阻器件与 RFID 标签结合，实现微特斯拉量级磁场的非侵入式无线感知。它体现了“RFID
不只是身份标签，而是可被扩展为通用物理传感接口”的系统思路。
可借鉴点 可借鉴传感器-射频耦合设计：先通过专用敏感器件把目标物理量映射为可被 RF 读取的变化，再由无
线链路完成远程采集。

11
TagStroke: Stealthy Keystroke Inference via Passive RFID Arrays Beneath Keyboards
MAIN CONFERENCE · RFID array / keystroke / fine-grained interaction / privacy
原文 https://doi.org/10.1109/INFOCOM59046.2026.11571296
论文概述 利用键盘下方的被动 RFID 阵列，从细微局部交互引起的 RF 变化中推断按键行为。论文从侧信道角
度展示了被动射频阵列对细粒度人体-物体交互的高敏感性。
可借鉴点 值得关注“空间阵列 + 微动作”的编码能力，同时也提醒无线感知系统必须考虑隐私泄露与非预期语
义恢复。

Room-scale 2D Passive Acoustic Tracking and Gait Recognition using a Smart Speaker
MAIN CONFERENCE · acoustic sensing / tracking / gait / multi-task

CloakFi: Metasurface-Enabled Privacy Protection for Wi-Fi Integrated Sensing and
Communication
MAIN CONFERENCE · Wi-Fi ISAC / metasurface / privacy
原文 https://doi.org/10.1109/INFOCOM59046.2026.11571421
论文概述 从隐私防护角度出发，利用可控超表面改变 Wi-Fi 感知所依赖的传播特征，使通信仍可工作但人体

可借鉴点 适合思考无线感知的可控隐私边界：未来基础模型越强，越需要在物理层设计可选择的语义隐藏机

14
A Geometric Algebra-informed NeRF Framework for Generalizable Wireless Channel
Prediction
MAIN CONFERENCE · wireless NeRF / geometric algebra / tokens / generalization
原文 https://doi.org/10.1109/INFOCOM59046.2026.11571298
论文概述 提出 GAI-NeRF，用几何代数注意力显式刻画射线与环境物体的交互，同时引入全局 token 聚合空
间-电磁特征，并重构传统静态射线追踪模块以提升跨场景泛化。论文在未见环境的无线信道预测上强调通用
性。
可借鉴点 这是把“物理先验 + token 化场景表示 + Transformer 式全局建模”结合得很直接的一篇。可重点借
鉴如何把几何关系编码进注意力，而不是仅把 CSI 当普通序列。

15
ChannelMAE: Self-Supervised Learning Assisted Online Adaptation of Neural Channel
Estimators
MAIN CONFERENCE · self-supervised / MAE / online adaptation / channel estimation
原文 https://doi.org/10.1109/INFOCOM59046.2026.11571223
论文概述 针对预训练神经信道估计器无法覆盖所有部署环境、在线又缺少真实信道标签的问题，引入基于
MAE 的自监督任务辅助在线适应，使模型可利用无标签接收数据持续更新。
可借鉴点 “主任务需要标签，但部署时没有标签”是无线感知同样常见的问题。可直接迁移其自监督辅助适应
范式，用于新房间、新用户、新设备的无标签校准。
