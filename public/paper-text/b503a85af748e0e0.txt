AI 顶会多模态研究论文汇总报告（2025–2026）
编制说明：本报告基于对 CVPR、ICCV、NeurIPS、ICML、ICLR、ACL、EMNLP、AAAI、ACM MM、
ECCV 等十大 AI 顶会的系统性检索与整理，覆盖 2025–2026 年度已接受或已发表的多模态相关论文，按会议分类
并辅以主题聚类分析。
一、总体趋势概览
根据对 26,000+ 篇顶会论文的计量分析（CVPR/ICLR/NeurIPS 2023–2025）以及各会议官方发布信息，多模态研
究在 2025–2026 年呈现以下五大宏观趋势：
趋势 具体表现
� MLLM 成为绝对主流 CVPR 2026 中多模态 LLM/VLM 的 Highlight 论文占比从 4.9%
跃升至 10.6%，成为最大单一子领域
� 从”理解”走向”推理” 多模态 Chain-of-Thought、GRPO/R1 风格的多模态强化学习成为
核心方法论
� 模态持续扩展 从图文双模态向视频、音频、3D、传感器、时间序列、文档、网页等全模
态扩展
� Agent 化趋势明显 多模态 Agent（Web/GUI/机器人）成为热门方向，评测基准快速跟进
� 效率与可解释性受关注 动态 token 剪枝、模态分解、轻量化适配、双曲空间训练等效率优化研究
激增

四、关键洞察与未来方向
4.1 七大关键洞察
1. 统一架构成为共识 从 Show-o2（自回归 + 流匹配）
、SAIL（单 Transformer）到 JavisGPT（音视频统一）
，原
生统一的多模态架构正在取代” 拼接式” 架构。Janus、MUSE-VL 等工作进一步推动了理解与生成的一体化。
2. 推理能力成为分水岭 R1-VL、Vision-R1、DIVA-GRPO、DocR1 等工作表明，多模态推理正从” 感知” 向” 深
度推理” 跃迁。GRPO 及其变体成为多模态 RL 的主流范式。
3. 长上下文视频是下一个战场 VideoChat-Flash
（10,000 帧）
、
Visual Context Window Extension、
CaReBench
等工作聚焦长视频理解，分层压缩与上下文窗口扩展是核心技术。
4. Agent 化是必然趋势 多模态 Agent 从 Web（WEB-COGREASONER）
、移动端（FingerTip 20K）到机
器人（3D QSR）全面铺开，评测基准（HippoCamp、AEIA-MN）快速跟进。
5. 评测体系快速演进 从 MMMU 到 MMMU-Pro、从 MME 到 MME-Reasoning、从 SpatialScore 到
Creation-MMBench，评测维度越来越细粒度，专业化基准大量涌现。
6. 模态持续扩展 传感器信号（SensorLM）
、心电图（MEIT）
、气候数据（CLLMate）
、分子结构（ChemVLN）
、
生物声学（BioVITA）等新型模态不断涌现，“万物皆可 token 化” 趋势明显。
7. 可解释性与安全性受重视 Layer-Wise Modality Decomposition（可解释融合）
、AEIA-MN（Agent 安全）
、
Medical Multimodal Model Stealing（医疗安全）
、DF-P2E（深度伪造可解释检测）等关注模型可信性。
4.2 未来方向预测
• 多模态世界模型：DriVerse、IRASim 等预示多模态世界模型将成为下一个热点。
• 具身多模态智能：HSImul3R、3D QSR 等推动多模态与机器人/具身智能深度融合。
• 多模态科学发现：ChemVLN、PoinnCARE、MTBBench 等表明科学领域是多模态 AI 的重要落地场景。
• 边缘端多模态：MiniCPM-V、动态 token 退出等推动 MLLM 向边缘设备部署。
• 多模态安全与对齐：随着 MLLM 在关键领域应用，安全性、隐私保护、对抗鲁棒性将成为刚需。
