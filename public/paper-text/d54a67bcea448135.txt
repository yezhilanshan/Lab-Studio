# 论文 最值得借鉴的点
1 Reading Your Actions: Learning Generalizable Action
Representations via Pre-training AEMG
把 EMG 直接建模为“词 + 句子”的物理语言，最接近新传感模态 Token 化。
2 A Geometric Algebra-Informed 3DGS Framework for
Wireless Channel Prediction
空间-电磁联合 Token + 物理传播约束，是物理先验进入 Transformer 的代表。
3 RISE: Single Static Radar-based Indoor Scene
Understanding
把多径 ghost reflection 从噪声变成几何信息，适合重新思考无线物理特征。
4 Point Cloud as a Foreign Language for Multi-modal Large
Language Model
原始点云直接离散成 LLM 词表，提供“非文本模态作为外语”的完整范式。
5 M4Human: A Large-Scale Multimodal mmWave Radar
Benchmark for Human Mesh Reconstruction
大规模同步 mmWave/RGB/深度/MoCap，适合做信号→几何→语言多级监督。
6 AdaRadar: Rate Adaptive Spectral Compression for
Radar-based Perception
用任务置信度在线调节雷达压缩率，可迁移为动态 Token / 采样预算。
7 MoEActok: A MoE-based Action Tokenizer for Vision-
Language-Action Models
用技能感知 MoE 量化连续动作，比单一 codebook 更适合复杂动作。
8 Action Motifs: Self-Supervised Hierarchical
Representation of Human Body Movements
Action Atom→Action Motif 的层次动作语法，特别适合长动作描述。
9 VQRAE: Representation Quantization Autoencoders for
Multimodal Understanding, Generation and
Reconstruction
连续语义 + 离散生成 Token 并存，直接回应统一表征与双向生成问题。
10 Perceptual-Evidence Anchored Reinforced Learning for
Multimodal Reasoning
把“感知证据是否正确”放进 RL 奖励，避免只靠最终文本答案。
11 WorldMM: Dynamic Multimodal Memory Agent for Long
Video Reasoning
多类型、多时间尺度 Memory + Agent 自主取证，适合超长时序。
12 VideoARM: Agentic Reasoning over Hierarchical Memory
for Long-Form Video Understanding
observe-think-act-memorize 把长视频理解变成工具驱动的主动过程。
13 Act2See: Emergent Active Visual Perception for Video
Reasoning
让模型在推理中决定何时补看/生成视觉证据，可类比主动传感。
14 Temporal Interaction in Spiking Transformers with Multi-
Delay Mixer
多延迟机制强化脉冲时间交互，是 SNN 长时动态建模的高价值模块。
15 Motus: A Unified Latent Action World Model 理解、世界预测、动作统一进 latent action，适合多任务物理世界模型。

CVPR 2026 的 8 个方法趋势
把 83 篇论文放在一起看，最值得关注的不是单个模块，而是这些方法论方向正在同时发生变化。
01
无线建模从“信号特征”走向“物理传播
Token”
GAI-GS、RISE、GeRaF 2.0 都在把几何、多径、EM 关系显式写入
表示，而不再把环境物理过程交给网络黑盒拟合。
02
连续物理量正在被“语言化 / Token 化”
AEMG、SAGE3D、MoEActok、Action Motifs 都把动作或信号拆
成可组合离散单元，再学习跨时间的“语法”。
03
多模态对齐开始防止弱模态被绕过
PEARL 和 Hallucination-as-Cue 都强调：必须验证模型是否真的
用了感知证据，而不是最终答案看起来正确就算成功。
04
Token 压缩从“删得多”转向“删得对”
信息熵、层间 transition、未来多轮问题、query 反投影等都成为
压缩依据；压缩器开始与任务和推理过程共同设计。
05
长时序理解从全量输入转向主动取证
WorldMM、VideoARM、Act2See、LongVideo-R1 把 Memory、
检索、工具调用与视觉采样变成推理过程的一部分。
06
SNN 研究重心转向“时间结构是否真的被利用”
多延迟交互、时间互信息、主动遗忘、鲁棒评价等工作都在追
问：脉冲的时间维度到底贡献了什么，而不只看能耗。
07
World Model 开始统一理解、生成与动作
Motus、D4RT、ORV 等工作以结构化动态状态或 latent action 为
中间层，把预测、生成、几何和控制连接起来。
08
部署鲁棒性从“训练一次”走向“测试时治理”
TTA/CTTA、多模态稳定-可塑性分解、open-set 适应与动作相关
Token 选择，正在成为真实部署的重要方法层。

S RISE: Single Static Radar-based Indoor Scene Understanding NEW
CVPR 2026 Main Conference
论文概述 RISE 用单个静态毫米波雷达同时做室内布局重建与物体检测。其核心反转了“多径是噪声”的常规认知：通过 AoA/AoD 双
角度建模恢复 ghost reflection，再用 sim-to-real 分层扩散把碎片化雷达响应补全为结构化场景。
可借鉴点 特别适合研究“把多径从干扰变成信息”。可把不同传播路径视为互补证据，并进一步让语言模型解释“哪类反射对应什么
结构/动作”。
原文 · CVF Open Access / CVPR 2026
S A Geometric Algebra-Informed 3DGS Framework for Wireless Channel Prediction NEW
CVPR 2026 Main Conference
论文概述 GAI-GS 将 3D Gaussian Splatting 与几何代数注意力结合，把空间关系与电磁关系共同编码为 Token，显式建模射线与物体
交互，使多径、衰减、反射与绕射能在统一端到端架构中被表示。
可借鉴点 这是“物理 Token”最值得精读的工作之一：Token 不只包含数值特征，还编码空间-电磁关系，可直接启发时延-多普勒-角
度域与场景几何的联合建模。
原文 · CVF Open Access / CVPR 2026
S M4Human: A Large-Scale Multimodal mmWave Radar Benchmark for Human Mesh Reconstruction
CVPR 2026 Main Conference
论文概述 M4Human 是面向人体三维网格重建的大规模多模态毫米波雷达基准，规模约 66.1 万帧，包含毫米波原始张量、雷达点
云、RGB、深度与 MoCap 三维人体网格/轨迹等同步标注，覆盖多主体与多动作。
可借鉴点 它提供了“原始无线信号 - 几何人体 - 视觉 - 动作”多级监督链路，可用于研究无线编码器、跨模态对齐、动作描述生成，
以及从低级物理信号到高级语义的桥接。
原文 · CVF Open Access / CVPR 2026
S mmWaveFlow: Unified Enhancement and Generation of mmWave Human Point Clouds
CVPR 2026 Main Conference
论文概述 论文把毫米波人体点云的增强与生成统一到 Flow Matching 框架中，通过跨模态潜空间对齐和面向点云起 点分布设计的流
建模，使稀疏、噪声较大的毫米波点云变得更完整，也能生成可用于数据扩充的样本。
可借鉴点 可直接启发“无线信号生成/补全”方向：先学习一个与视觉或几何语义对齐的潜空间，再在该空间做生 成，比直接在原始
雷达张量上生成更容易稳定，也能为下游识别或语言描述提供更丰富的中间表征。
原文 · CVF Open Access / CVPR 2026
S AdaRadar: Rate Adaptive Spectral Compression for Radar-based Perception NEW
CVPR 2026 Main Conference
论文概述 AdaRadar 面向高维雷达数据的带宽瓶颈，依据检测置信度对压缩率做在线反馈调节，并结合 DCT 频域稀疏性、系数裁剪
与尺度量化，在任务性能几乎不变的情况下实现百倍级特征压缩。
可借鉴点 非常适合迁移到“自适应无线 Token 预算”：让下游任务置信度决定保留多少频谱/时频 Token，而不是固定压缩率或固定
采样率。

S Seeing through boxes: Non-Line-of-Sight 3D Reconstruction from Radar Signals NEW
CVPR 2026 Main Conference
论文概述 GeRaF 2.0 面向雷达非视距 3D 重建，将封闭区域外部的 LoS 几何与视觉先验显式引入 RF 神经场，用可见区域的物理约束
指导信号传播到 NLoS 区域，从而减少 SDF 表面歧义并提升隐藏物体几何质量。
可借鉴点 关键不是“再加一个视觉模态”，而是把可观测几何写进传播模型。对无线感知可借鉴为：用场景结构、反射面或人体先验
约束多径/遮挡下的物理 Token。
原文 · CVF Open Access / CVPR 2026
S WiTTA-Bench: Benchmarking Test-Time Adaptation for WiFi Sensing
CVPR 2026 Main Conference
论文概述 面向 WiFi 感知在环境、用户和设备变化下严重掉点的问题，论文系统比较了多类测试时自适应（TTA）方 法，并同时覆盖
在线与离线测试适应设置。作者还构建了异构设备配对数据，用于分析不同域偏移之间的层级关系 与可迁移性。
可借鉴点 若做毫米波/WiFi 跨环境泛化，这篇最值得借鉴的是“训练后再适应”的实验范式：把场景、主体、设备分 别作为域偏移变
量，建立统一评测协议，而不是只报告单一数据集上的随机划分。
原文 · CVF Open Access / CVPR 2026
S Expanding mmWave Datasets for Human Pose Estimation with Unlabeled Data and LiDAR Datasets
CVPR 2026 Main Conference
论文概述 该工作关注毫米波人体姿态数据稀缺，提出同时利用未标注毫米波数据和已有 LiDAR 人体数据扩充训练集：一方面以伪标
签吸收无标注样本，另一方面通过显式转换把 LiDAR 数据映射到更接近毫米波观测的形式。
可借鉴点 这是解决“无线数据难采、难标”的实用途径：可用视觉/骨骼/视频数据生成中间伪标签，再通过物理约束或信号仿真把监
督迁移回无线域。
原文 · CVF Open Access / CVPR 2026
A Wave-Former: Through-Occlusion 3D Reconstruction via Wireless Shape Completion
CVPR 2026 Main Conference
论文概述 Wave-Former 利用毫米波能够穿透部分遮挡的物理特性，从无线观测中补全被视觉遮挡的三维形状。方法 把物理感知与形
状补全结合，并利用合成数据扩充训练，使遮挡区域的三维召回率明显提升。
可借鉴点 重点看它如何把“无线的物理优势”变成模型结构约束。相关工作若想突出无线相对视觉的不可替代性， 可以围绕遮挡、
暗光、隐私、穿透等场景设计任务，而不只是把雷达当成另一种输入模态。
原文 · CVF Open Access / CVPR 2026
A Rascene: High-Fidelity 3D Scene Imaging with mmWave Communication Signals
CVPR 2026 Main Conference
论文概述 Rascene 探索直接利用毫米波通信 OFDM 信号进行三维场景成像，在通信链路上叠加感知能力。方法通过 多帧空间融合与
置信度加权投影，提高由通信信号重建场景结构的精度与稳定性。
可借鉴点 适合你从“通信信号 → 感知 Token”角度阅读。它体现了 ISAC 中如何把时延/角度等物理信息汇聚为可学 习的空间表征，
也可启发你构造基于物理域的 Token 而非直接套用视觉 Token。

世界模型、4D 动态场景与 Latent Action
从“预测下一帧”走向统一的几何、动作、生成与控制中间状态；适合思考可解释的动态世界表征。 本节 8 篇
S Efficiently Reconstructing Dynamic Scenes One D4RT at a Time
CVPR 2026 Main Conference
论文概述 CVPR 2026 Best Paper。D4RT 用统一 Transformer 处理动态场景的深度、时空对应和相机参数等多种几 何量，强调在同
一表征中联合解决四维重建问题，并兼顾计算效率。
可借鉴点 虽然不是无线论文，但其“统一时空表示 + 多任务几何监督”非常值得借鉴。可类比构建统一无线时空 Token，同时预测动
作、速度、人体结构、语言描述，而不是每个任务单独做模型。
原文 · CVF Open Access / CVPR 2026
S Native and Compact Structured Latents for 3D Generation
CVPR 2026 Main Conference
论文概述 CVPR 2026 Best Student Paper。论文提出紧凑、结构化的三维潜变量表示，用稀疏体素同时承载几何与 外观，再配合
VAE 与大规模 Flow Matching 生成模型，在效率与三维质量之间取得良好平衡。
可借鉴点 值得看它如何设计“结构化潜变量”。无线信号也不一定要直接压成一串无结构 embedding，可以保留 range/Doppler/
angle/时间等坐标关系，形成可生成、可解释的结构化 latent。
原文 · CVF Open Access / CVPR 2026
S Motus: A Unified Latent Action World Model NEW
CVPR 2026 Main Conference
论文概述 Motus 用 Mixture-of-Transformer 统一理解、视频生成与动作三个专家，并通过 UniDiffuser 风格调度在 world model、
VLA、inverse dynamics、视频生成与视频-动作联合预测间切换；同时从光流学习 latent action。
可借鉴点 可借鉴“统一潜在动作空间”作为多任务接口：让感知、预测、生成和控制共享同一动作 Token，而不是每个任务各自定义
标签空间。
原文 · CVF Open Access / CVPR 2026
S Dexterous World Models
CVPR 2026 Main Conference
论文概述 论文把世界模型用于灵巧操作，通过场景与动作条件的视频扩散模型生成可交互的未来视觉结果，使模型 能够在数字环境
中模拟手部动作对场景的影响。
可借鉴点 若想把无线感知扩展到世界模型，可借鉴“感知状态 + 动作条件 → 未来观测”的训练目标：不只识别当前 动作，还预测未
来毫米波/视觉观测，再让语言模型在预测世界中做规划与解释。
原文 · CVF Open Access / CVPR 2026
A ORV: 4D Occupancy-centric Robot Video Generation NEW
CVPR 2026 Main Conference
论文概述 ORV 用 4D 语义 occupancy 缩小稀疏控制与稠密像素之间的表示鸿沟：7-DoF action 通过 Action-Expert AdaLN 注入，4D
occupancy 渲染作为视觉先验，引导多视角一致的视频生成。
可借鉴点 世界模型不一定直接从动作到像素，可先预测更物理、更结构化的中间状态，再生成观测；无线场景也可先预测人体/占用/
轨迹再生成信号。

A MoRe: Motion-aware Feed-forward 4D Reconstruction Transformer NEW
CVPR 2026 Main Conference
论文概述 MoRe 是前馈式动态 4D 重建模型，通过 attention-forcing 在训练中显式教模型分离动态运动与静态结构，并用 grouped

量更新。
原文 · CVF Open Access / CVPR 2026
A NitroGen: An Open Foundation Model for Generalist Gaming Agents
CVPR 2026 Main Conference

标是在不同游戏间学习可迁移的视觉-动作策略。
可借鉴点 这篇适合从“通用 Agent 的数据规模与动作词表”角度阅读。对感知 Agent，可思考把动作/采样/传感器调 用也离散成可学
习的操作 Token，让模型学会何时看、看哪里、调用哪个模态。

测试时自适应、域泛化与模型诊断
把部署后的分布漂移、未知类别、模态失衡与“模型是否真的使用证据”单独拿出来建模。 本节 7 篇
S Understanding the Role of Hallucination in Reinforcement Post-Training of Multimodal Reasoning Models
NEW
CVPR 2026 Main Conference
论文概述 论文提出 Hallucination-as-Cue 诊断框架：故意删掉或替换完成任务必需的某一模态信息，迫使模型只能“幻觉式推
理”，再观察 RL 后训练是否仍提升。结果显示即使视觉证据被破坏，RL 也可能显著变好。
可借鉴点 这是验证“模型到底有没有使用物理模态”的关键方法：做模态消融/反事实腐蚀后再看 RL 收益，防止把语言捷径误判为跨
模态推理能力。
原文 · CVF Open Access / CVPR 2026
A Decoupling Stability and Plasticity for Multi-Modal Test-Time Adaptation NEW
CVPR 2026 Main Conference
论文概述 DASP 先诊断哪个模态发生偏移，再对不同模态实施非对称适应：偏移模态启用 plastic 分支学习域特征，稳定模态绕过
plastic 分支并用 KL 约束保持知识，缓解负迁移与灾难性遗忘。
可借鉴点 非常适合多传感器：不要默认所有模态一起更新。先判断无线、视觉、惯性中谁偏了，再只给问题模态更多可塑性，稳定模
态作为锚点。
原文 · CVF Open Access / CVPR 2026
A Condensed Test-Time Adaptation of VLMs for Action Recognition NEW
CVPR 2026 Main Conference
论文概述 ConDA 是训练自由的 VLM 动作识别 TTA：先用视觉-文本对齐概率挑出语义 patch，再依据 patch 视觉相似度构造时空
tube，用语言语义反向指导视觉缓存的组织，减少 vision-vision 与 vision-text 映射不传递的问题。
可借鉴点 可用于“文本语义指导物理适应”：先用类别/描述语义定位最相关信号区域，再用这些区域构建测试时记忆，而不是无选
择缓存所有样本。
原文 · CVF Open Access / CVPR 2026
A Back to Source: Open-Set Continual Test-Time Adaptation via Domain Compensation NEW
CVPR 2026 Main Conference
论文概述 DOCO 面向“域持续变化 + 未知类别同时出现”的 OCTTA。它动态分离 ID/OOD 样本，只用 ID 学习 domain
compensation prompt，把特征统计拉回源域并保持语义结构，再把补偿传播到 OOD 样本用于更可靠检测。
可借鉴点 无线开放环境常同时出现新场景和新动作，可显式分离“域变化”与“语义新颖性”，避免把未知动作误当成环境偏移直接
适应掉。

如果要把这些论文变成研究路线
最后不按会议主题，而按“能怎么组合成一个可做的研究问题”重新串一次。
ROUTE 01
把无线信号真正变成“物理语言”
先定义可解释物理事件或动作原子，再量化为离散 Token；保留
一条连续细节分支，最终与文本共享 Transformer，而不是只做
单层 Projector。
GAI-GS / AEMG / SAGE3D / MoEActok / VQRAE
ROUTE 02
生成更长、更细的动作描述
用人体几何或动作 Motif 提供中层监督，把长序列分成阶段并写
入多尺度 Memory；语言模型按需回看关键物理片段后生成长描
述。
M4Human / Action Motifs / Superman / WorldMM /
VideoARM
ROUTE 03
让计算预算随“信息量”动态变化
压缩率、帧/Token 保留率、推理轮数都可由任务置信度或信息量
决定；把“处理多少数据”本身变成可学习决策。
AdaRadar / ApET / IF-Prune / TimeViper / APPO
ROUTE 04
验证模型是真的看懂了物理模态
建立反事实与模态腐蚀评测；训练时加入感知证据奖励，部署时
诊断哪一模态发生域偏移并进行非对称适应。
WiTTA-Bench / PEARL / Hallucination-as-Cue / DASP
