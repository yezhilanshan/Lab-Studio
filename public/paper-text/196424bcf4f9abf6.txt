# 论文 最值得借鉴的点
11 Chain-of-Thought Compression Should Not Be Blind: V-
Skip for Efficient Multimodal Reasoning via Dual-Path
Anchoring
对传感器 CoT/Token 压缩很有启发：不能只删语言冗余，而应保留与物理证据强绑定的
步骤；可定义“信号锚定分数”约束推理压缩。
12 Diffuse Thinking: Exploring Diffusion Language Models as
Efficient Thought Proposers for Reasoning
非常值得借鉴“异构推理器协作”：一个模型负责并行提出多种动作/物理解释，另一个
模型负责验证与收敛。
13 CreditDecoding: Accelerating Parallel Decoding in Diffusion
Large Language Models with Trace Credit
值得迁移“轨迹信用”思想：判断一个动作/语义片段是否可靠时，不只看最后一步置信
度，而看它在多轮推理或多尺度观测中是否持续稳定。
14 Parallelism and Generation Order in Masked Diffusion
Language Models: Limits Today, Potential Tomorrow
这是理解 DLM 是否真的适合复杂推理的关键参考；可把生成顺序本身作为可学习变量，
研究动作描述是否应先生成全局事件，再补局部细节。
15 Agentic Memory: Learning Unified Long-Term and Short-
Term Memory Management for Large Language Model
Agents
可把传感器历史管理做成可学习动作：Agent 自己决定哪些事件值得长期保存、何时回查
原始信号、何时只保留摘要，而不是固定滑窗。
16 OCR-Memory: Optical Context Retrieval for Long-Horizon
Agent Memory
对传感器尤其有启发：历史可以以谱图、轨迹图或压缩视觉画布保存，Agent 先“看图定
位”再回取对应原始片段，形成非文本长期记忆。
17 Retrieval as Generation: A Unified Framework with Self-
Triggered Information Planning
可把“检索”泛化为“调用物理观测”：让模型在生成动作解释时自行发出控制 Token，
决定是否回看原始信号、换时间窗、调用某个信号处理工具。
18 Reasoning with Memory: Adaptive Information
Management for Retrieval-Augmented Generation
特别适合“信号证据逐步累积”的任务：让一个小模块管理当前物理工作记忆，而不是把
每次检索出的所有帧和文本都不断追加进上下文。
19 Every Token Counts: Generalizing 16M Ultra-Long Context
in Large Language Models
对于分钟级甚至小时级传感序列，层级结构比简单扩大窗口更合理：短程保留高分辨率，
长程通过稀疏跳转访问关键历史事件。
20 Discovering the Gems in Early Layers: Accelerating Long-
Context LLMs with 1000x Input Token Reduction
很适合长传感器序列：先用浅层编码器筛掉大量无关帧/频谱单元，只有候选物理 Token
进入深层 LLM，形成“早层检索、深层推理”的分工。

ACL 2026 的 8 个方法趋势
把 100 篇论文放在一起看，最值得关注的不是单个模块，而是这些方法论方向正在同时发生变化。
01
非文本信号进入 LLM：从 Projector 转向“证据化”
时间序列、音频、脑信号等工作越来越强调先提取可验证结构、因果
关系、专用表征或多专家线索，再由 LLM 组织语义。
02
时间序列任务从预测走向 caption、因果与符号发现
CaTS-Bench、Augur、SymbolBench 表明，数值序列正在被当作可
解释推理对象，而不只是预测输入。
03
多模态对齐开始正视“模态坍塌”
多篇论文发现共享空间可能被文本主导，因此出现 modality
dropout、结构约束、表征诊断与 evidence attribution。
04
DLM 的重点转向“生成轨迹”而不是只换模型骨干
并行顺序、语义收敛、草稿修订、历史信用和 AR-DLM 混合验证，正
在成为扩散语言模型的核心创新区。
05
Agent Memory 变成可学习的状态管理系统
记忆不再只是向量数据库，而是包含 store / update / discard /
consolidate / navigate 等操作与层级生命周期。
06
长上下文从“更长窗口”走向“结构化选择”
早层筛选、结构 KV、层级稀疏、周期校准都在回答同一问题：哪些
Token 值得持续占用计算和内存。
07
RAG 控制被内生到推理策略
模型开始自行决定什么时候检索、缺哪类 bridge evidence、是否应改
变遍历路径，而不是固定“一次检索→生成”。
08
评测开始要求过程一致性与可归因
最终答案正确已经不够；新的 benchmark 检查中间过程、证据颗粒
度、Token 边界和因果干预，防止模型靠先验取巧。
