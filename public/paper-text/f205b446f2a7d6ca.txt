KDD 2026 的 8 个方法趋势
把这 36 篇放在一起看，更值得关注的是这些“可以抽象成研究范式”的共同变化，而不是单个模块本身。
01
非文本模态进入 LLM：从“硬投影”走向弱对齐 +
证据补偿
Vistar 与相关工作更强调表征近似对齐、外部检索和证据补充，而不
是要求连续传感信号一次投影就拥有完整语言语义。
02
Time-Series Tokenizer 成为独立研究对象
TiWeaver 与 tokenizer 控制实验说明：窗口边界、patch 结构和输入
编码本身可能决定大部分性能，必须与 backbone 能力解耦。
03
OOD 评测从随机划分走向多轴拆解
HAROOD 把跨人、跨位置、跨数据集、跨时间等分布外变化拆开测
试，暴露随机划分无法看见的真实泛化缺口。
04
长时序建模开始同时重视蒸馏、频域和生成先验
TimeDistill、LoFT-LLM、TimeBridge 等工作分别从跨架构蒸馏、低
频结构和 diffusion / bridge prior 降低长序列建模难度。
05
RAG 从“相似度检索”升级为分布感知决策
SARAF 与 HyRAG 表明检索空间、分布漂移、样本多样性和知识层级
都应该进入 retrieval policy，而不是只做最近邻。
06
持续学习重点转向梯度冲突和模态漂移
G2LoRA 等工作不再只加 replay，而是直接约束任务间梯度方向和不
同模态的更新节奏。
07
Agent 研究强调预算调度、长期记忆与真实反馈闭环
Prompt difficulty、TuneAgent、显式/隐式 Memory 等工作共同关
注：何时值得花算力、信息放哪里、如何用环境反馈校正策略。
08
Scientific AI 更强调结构/物理先验与不确定性分布
KFTD、Physics-enhanced Neural Operator、FlowTime 等工作说
明：连续时间、物理方程、生成式分布建模正在替代单纯点预测。

10 个可直接迁移的创新模板
下面不是论文复述，而是从精选工作中抽出来的“研究结构”。做选题时可以直接拿它们去映射自己的数据、损失、训练流程和评测。
01 弱配对分阶段对齐
训练阶段只要求表征空间大致对齐；推理阶段用 RAG/检索结果补
足细粒度语义。
来源：Vistar
02 自适应物理 Token
不用固定窗口切传感序列，依据变化密度、跨通道一致性或事件
边界动态分块。
来源：TiWeaver
03 多轴 OOD Benchmark
把跨人、跨环境、跨设备、跨时间分别测，避免随机划分掩盖泛
化问题。
来源：HAROOD
04 Backbone/Tokenizer 解耦消融
用交换实验和随机/冻结 backbone 判断性能到底来自输入表征还
是大模型本身。
来源：Tokenizer Bias Study
05 跨架构能力蒸馏
把频域、多尺度或长时依赖等“结构能力”蒸馏到轻模型，而不
是只蒸馏输出概率。
来源：TimeDistill
06 语言可控信号生成
用自然语言描述希望的物理序列变化，并通过共享表征 + 解码器
完成可控编辑。
来源：InstructTime
07 分布感知 RAG
检索不仅看相似度，还看 regime 多样性、分布漂移与置信度，动
态决定是否信任历史样本。
来源：SARAF
08 跨模态持续学习防漂移
用梯度正交/投影降低新旧任务冲突，同时协调两种模态编码器的
更新速度。
来源：G2LoRA
09 层级知识的几何匹配
当知识具有树/层级结构时，用双曲或层级索引替代平铺向量库，
进行粗到细检索。
来源：HyRAG
10 物理先验 + 学习算子
把传播/运动/PDE 约束作为辅助机制或先验空间，与数据驱动网
络共同学习。
来源：KFTD / Physics-enhanced Neural Operator

S Vistar: Enhancing the Perception Capability of LLMs under Imprecise IMU-Text Alignment
KDD 2026 V.1 · Research · IMU / LLM / Cross-modal Alignment / RAG
论文概述 面向 IMU 高频时序与自然语言难以精确对齐的问题，Vistar 采用“离线跨模态对齐 + 在线检索增强”的两阶段思路。训练时以预训练视觉与
语言编码器作为锚点，通过层次化跨模态对比学习训练 IMU 编码器；推理时再利用结构关系筛选相似 IMU 对应文本，辅助 LLM 生成更贴合信号的描
述。
可借鉴点 这是本届最值得拆的方法之一：不要强求传感器与文本一次性完美对齐，而是把“表征对齐”和“推理时补偿”拆开；尤其适合迁移到毫米
波、WiFi、雷达等弱语义物理信号。
原文 / DOI 10.1145/3770854.3780181
S HAROOD: A Benchmark for Out-of-distribution Generalization in Sensor-based Human Activity Recognition
KDD 2026 V.1 · Benchmark · Sensor HAR / OOD Generalization
论文概述 系统研究传感器行为识别在真实分布偏移下的泛化问题，围绕跨人、跨佩戴位置、跨数据集与跨时间等 OOD 场景构建统一评测，并比较多类
代表方法。核心结论是：不同 OOD 类型的困难来源不同，没有单一方法能在所有场景稳定占优。
可借鉴点 适合直接借鉴其“OOD 维度拆分 + 统一协议”设计。做无线感知或人体行为理解时，可把跨人、跨环境、跨设备、跨时间分别建
benchmark，而不是只做随机训练/测试划分。
原文 / KDD 2026 V.1；标题与录用信息经 proceedings/学术索引核对
S ChannelMTS: A Multi-modal Time-Series Framework for High-Speed Railway Channel Prediction
KDD 2026 V.1 · Wireless Channel / Multimodal Time Series
论文概述 将高速铁路无线信道预测建模为多模态时间序列学习问题，重点不是只根据单一历史 CSI 外推，而是利用多来源动态信息共同描述快速变化
的信道状态。其价值在于把通信物理量与时序多模态建模连接起来，为复杂移动场景的信道预测提供统一学习框架。
可借鉴点 建议重点看它如何定义“模态”、如何同步不同频率/来源的数据以及如何融合。对通信感知研究而言，“物理信号 + 场景上下文 + 历史序
列”的联合预测是很可迁移的设计方向。
原文 / DOI 10.1145/3770854.3783957
A UniLLM: A Unified Large Language Model for Multi-Modal Urban Dynamics Prediction
KDD 2026 V.1 · LLM / Urban Computing / Multimodal Forecasting
论文概述 针对城市数据中交通、移动、环境等多种动态信号相互影响，而传统方法往往按单模态和单任务分别建模的问题，论文探索用统一 LLM 框架
建模多模态城市动态，并利用跨模态依赖帮助不同预测任务共享知识。
可借鉴点 值得关注“异构时序如何统一成 LLM 可处理表示”以及多任务共享方式。它提供了一个通用范式：先统一接口/Token，再让大模型承担跨
模态依赖建模，而不是为每种传感器各训练一套 backbone。

KDD 2026 V.1 · Multimodal LLM / Benchmark / Spurious Correlation

S KFTD: Koopman-Fourier Time-Differentiable Network for Continuous Ocean Spatiotemporal Forecasting
KDD 2026 V.1 · Spatiotemporal Forecasting / Koopman / Physics-informed
论文概述 面向连续时间海洋时空预测，KFTD 将复杂非线性动力学映射到更易处理的 Koopman 表示空间，并结合 Fourier 机制实现连续时间插值/预
测；同时引入物理约束，使预测不仅拟合数据，也更符合动力学规律。论文强调连续时间建模与计算效率。
可借鉴点 非常适合借鉴“数据驱动表示 + 物理先验”的组合，而不是把 PDE/物理约束生硬塞进主干网络。对无线信道、雷达运动状态等具有明确动
力规律的数据同样适用。
原文 / DOI 10.1145/3770854.3780278
A How to Train Your Mamba for Time Series Forecasting
KDD 2026 V.1 · Mamba / State Space Model / Forecasting
论文概述 围绕 Mamba/状态空间模型用于时间序列预测的关键训练与建模选择展开系统研究，关注序列建模结构如何适应时序数据，而不是简单把
NLP 版本 Mamba 原样迁移。其价值更像“方法学与训练配方”而非只提出一个更大的新模型。
可借鉴点 适合在尝试 Mamba、SSM 或 SNN 时参考其消融逻辑：先分离输入表示、归一化、通道交互、序列扫描等因素，再判断性能来源，避免把
收益笼统归因于新 backbone。
原文 / DOI 10.1145/3770854.3780279
S TimeDistill: Efficient Long-Term Time Series Forecasting with MLP via Cross-Architecture Distillation
KDD 2026 V.1 · Knowledge Distillation / Long-term Forecasting / Efficient Model
论文概述 观察到 Transformer、CNN 等架构会分别捕获时间域/频率域中的多尺度与多周期模式，论文用跨架构知识蒸馏把这些互补模式传给轻量
MLP。实验中学生模型不仅大幅减小参数和推理成本，在多个数据集上还可超过教师。
可借鉴点 核心可迁移点是“蒸馏结构能力，而不仅蒸馏 logits”。若希望把大模型/复杂时序模型压到 SNN 或轻量感知模型中，可分别蒸馏多尺度、
周期、频域或中间表征。
原文 / arXiv:2502.15016 · KDD 2026
A TimeBridge: Better Diffusion Prior Design with Bridge Models for Time Series Generation
KDD 2026 V.1 · Time-series Generation / Diffusion Bridge
论文概述 重新审视时序扩散生成中“从固定高斯噪声出发”的先验选择，使用 bridge model 在更合理的先验分布与真实数据之间建立生成过程，并针
对无条件/条件时序生成设计更贴近时间序列结构的 prior。
可借鉴点 很适合借鉴到生成式无线信号建模：扩散模型未必必须从白噪声开始，可以选择保留尺度、周期、低频趋势或粗粒度物理结构的先验，让生
成过程只负责补足难建模残差。

S Instruction-based Time Series Editing
KDD 2026 · InstructTime / Natural-language Control / Time-series Editing

论文概述 把观看时长从单点回归重构为连续生成式预测问题，用 flow-based 模型刻画多峰、个体异质的时长分布，并通过个性化先验让生成过程适配
不同用户。论文还提供面向工业推荐的离线与在线验证。
可借鉴点 “预测完整分布而不是一个均值”很值得迁移：动作持续时间、事件发生时间、信号未来轨迹都可能多模态，用 flow/diffusion 建条件分布
能表达不确定性，而不是强行 MSE 回归。

A SpaCellAgent: A Self-Evolving LLM-Based Multi-Agent Framework for Trajectory Analysis
KDD 2026 V.2 · AI for Sciences / Multi-Agent / Trajectory Analysis
论文概述 将 LLM 多智能体用于生物轨迹分析，通过角色分工协作处理数据分析、假设生成与结果检查，并强调自演化机制，使 Agent 在任务反馈中改
进分析策略。场景虽然是单细胞/空间组学，但本质是复杂轨迹与多阶段推理。
可借鉴点 适合参考多 Agent 如何围绕同一时序/轨迹数据分工：一个负责信号特征，一个负责生物/物理知识，一个负责反思验证，再由协调者综合。
比让单个 LLM 同时承担所有职责更清晰。

如果要把这些论文变成研究路线
最后不要按“会议论文列表”记忆，而要按自己的问题把论文串成方法链。
ROUTE 01 无线信号 → 语言
Vistar → HAROOD → TiWeaver → Instruction-based Time Series
Editing
先解决“信号是否真正贡献语义”和“Token 如何构造”，再做生成式
长描述。
ROUTE 02 时序基础模型 / 轻量化
Tokenizer Bias Study → TimeDistill → How to Train Your Mamba →
LoFT-LLM
先区分 tokenizer 与 backbone，再看长依赖和跨架构能力蒸馏。
ROUTE 03 RAG / 长期记忆
SARAF → HyRAG → Explicit vs. Implicit Memory → CTIConnect
从“最近邻检索”升级为分布感知、层级检索和显式/隐式记忆协同。
ROUTE 04 Agent + 可验证反馈
Prompt Difficulty → TuneAgent → Thought-Augmented Planning
→ SpaCellAgent
研究“何时值得调用工具/花算力”，并用环境反馈或角色分工约束推
理。
ROUTE 05 物理先验 / 生成式预测
KFTD → Physics-enhanced Neural Operator → FlowTime →
TimeBridge
把连续时间、算子、PDE 先验和条件分布建模加入数据驱动方法。
