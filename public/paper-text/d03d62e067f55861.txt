1. 研究范围、筛选方法与统计概览
1.1 会议范围
本次检索覆盖机器学习核心会议 ICLR、ICML、NeurIPS，计算机视觉核心会议 CVPR、
ICCV、ECCV，以及自然语言处理核心会议 ACL、EMNLP。这些会议对多模态研究的关注重点不
同：机器学习会议更重视学习范式、泛化和统一建模；视觉会议更重视视觉表征、视频、3D、密集预
测与具身任务；NLP 会议则更强调语言 grounding、评测、智能体、多语言和真实用户场景。

2. 核心结论：近三年多模态研究的十条主线
2.1 “ ”
从 外挂视觉编码器 走向原生统一多模态模型
DreamLLM、VisionLLM v2、NaViL、AIMv2、TA-Tok 和原生多模态规模规律研究，均在尝
试缩小视觉编码器、连接器和语言模型之间的接口瓶颈。长期目标不是把视觉特征简单投影到 LLM，
而是在统一 Token、统一目标或统一骨干中同时完成理解、生成和任务执行。

2.2 多模态范围从图文扩展到全模态与真实传感器
视频、环境声音、语音、3D、触觉、脑信号和时间序列快速进入主会。CREMA、TriSense、
SAVVY、Touch-Vision-Language、OmniBind、Time-VLM 和 By My Eyes 表明，研究焦点正在
从静态语义对齐转向时序同步、空间关系、物理属性和跨传感器互补。
2.3 缺失模态、模态冲突与强模态主导成为可靠性核心
过去多模态融合通常默认模态完整且一致，但真实系统存在遮挡、噪声、不同步和语义冲突。
ICLR、ICML、ICCV、ECCV 均出现针对模态偏好、缺失模态、冲突输入和表示解耦的工作。这类
问题与无线感知中的遮挡、信号衰落和传感器失效高度同构。
2.4 多模态推理开始强调空间、物理和可验证中间过程
Do VLMs Represent Space、FRIEDA、SAVVY、Visual Thoughts、Core Knowledge
Deficits 等研究说明：高分 VQA 不等于真正理解空间、数量、物理和因果。研究正在从输出答案转向
分析模型内部是否形成可组合、可定位、可验证的视觉或符号中间表示。
2.5 评测从单图问答走向多图、交错输入、智能体与真实用户
MMIE、MIBench、BLINK、VisualWebArena、GUI-World、CODIS 等基准将评测扩展到
多图关系、交错图文、网页操作、上下文依赖和无障碍辅助。未来评测需要同时测量准确性、视觉依
赖度、幻觉、效率和鲁棒性。
2.6 高效多模态模型的主战场是视觉 Token
Dynamic-LLaVA、MMInference、VisionTrim、ViTSP、Task-Related Token
Compression 等方法集中解决视觉 Token 数量过多的问题。核心策略包括动态选择、任务相关压
缩、稀疏注意力、浅层特征利用和无需训练的 Token 裁剪。
2.7 理解与生成的统一正在重塑训练目标
DreamLLM、Video-LaVIT、TIGeR、统一生成-判别训练、LaViDa 和视觉可解码 Token 等工
作尝试让模型既能理解输入，又能生成图像、视频、声音或中间视觉表示。这为传感器数据的双向建
模——感知到文本、文本到物理 Token——提供了可借鉴路径。
2.8 多模态智能体从对话模型走向工具、网页、导航和机器人控制
VisualWebArena、LLaVA-Plus、GUI-World、OTTER、ContextNav 等论文表明，多模态
能力正在被置于闭环决策系统中。模型不仅回答问题，还必须观察、规划、调用工具、执行动作并依
据反馈修正。
2.9 数据问题从规模转向质量、组成和可诊断性
Re-Imagining Multimodal Instruction Tuning、Apollo、Cambrian-1 等工作系统分析数据
质量、模态比例、任务覆盖和采样策略。单纯增加图文对已不足以解决细粒度感知、物理推理和跨域
泛化问题。

2.10 可信多模态需要显式证据与不确定性
模态冲突、语言偏置、跨模态记忆、机器遗忘、后门和多模态幻觉研究快速增长。未来可信系统
应能指出使用了哪些模态证据、各模态可信度如何、冲突时为何选择某一信息，以及不确定性如何影
响最终决策。

4. 面向无线感知与多传感器研究的迁移启示
对于无线感知、毫米波雷达、WiFi CSI、视觉与惯性传感器融合而言，最值得关注的并不是把传
感器数据直接接入某个 LLM，而是多模态顶会论文反复处理的五类基础矛盾：物理数据与语言语义之
间存在表示鸿沟；模态质量随时间变化；模态可能缺失或冲突；不同任务需要不同模态；高维连续序
列带来 Token 和计算压力。
4.1 “ ” “
从 强制对齐 转向 共享信息 + ”
模态特有信息
DeCUR、Representation Decoupling、Total Correlation Maximization 等工作说明，完全
把所有模态压入同一表示可能丢失物理细节。无线数据中距离、多普勒、角度、相位和环境噪声既有
共享因素，也有模态特有信息，更适合显式分解后再融合。
4.2 将模态可信度建模为动态变量
Modality Preference、Modality Conflict、Balanced Multimodal Learning 等工作表明，
固定融合权重无法适应遮挡、信号衰减和传感器故障。可进一步研究按时间、样本和任务估计可信
度，并让模型在冲突时输出不确定性和证据来源。
4.3 物理 Token “
不必一开始就追求 像文本 Token”
统一离散 Token 适合生成和双向建模，但连续 Token 更容易保留精细物理量。可采用分层策
略：底层连续表征保存测量信息，上层学习少量语义槽位或离散码，再与语言空间对齐。UniCode、
TA-Tok、Byte-Pair Visual Encoding 和 Patch-as-Decodable-Token 可作为参考。
4.4 优先研究长时序压缩，而不是只做单帧融合
无线感知数据通常由连续帧组成。MA-LMM、Video-LaVIT、MMInference、VisionTrim 和
Task-Related Token Compression 提供了记忆、运动 Token、稀疏注意力和任务相关压缩思路。
关键是保留事件变化和运动结构，而非平均池化所有帧。
4.5 构建真正诊断性的多模态感知基准
可借鉴 MMIE、BLINK、MIBench 和 Core Knowledge Deficits，把性能拆成：单模态可解
性、互补收益、缺失鲁棒性、冲突处理、跨环境泛化、开放类别和自然语言解释。这样才能区分模型
是在利用无线模态，还是依赖视觉/文本捷径。

4.6 传感器可视化是低成本接入 MLLM 的可行基线
By My Eyes 证明，把传感器序列转换成任务相关图像后输入 MLLM，可以减少长序列文本
Token 并提升多类感知任务。这一方案不一定是最终最优架构，但适合作为无需训练或少量训练的强
基线。

5. 20 篇优先阅读清单
1. Multimodal Learning Without Labeled Multimodal Data — ICLR 2024；对齐与表征学
习。研究在缺乏成对多模态标注时，如何利用非配对单模态数据学习可迁移的跨模态表示。
2. Quantifying and Enhancing Multi-modal Robustness with Modality Preference — ICLR
2024；模态平衡与鲁棒性。量化模型对某一模态的偏好，并通过训练机制降低强模态主导造成的性
能脆弱性。
3. Unified Language-Vision Pretraining with Dynamic Discrete Visual Tokenization —
ICLR 2024；统一建模与 Token 化。通过动态离散视觉 Token，将语言与视觉预训练统一到序列建
模框架中。
4. DreamLLM: Synergistic Multimodal Comprehension and Creation — ICLR 2024；理解
与生成统一。在一个自回归框架内协同建模多模态理解与图像生成，实现双向语义交互。
5. MMIE: Massive Multimodal Interleaved Comprehension Benchmark for Large Vision-
Language Models — ICLR 2025；评测与基准。构建大规模交错输入输出基准，评估模型在多
图、多文本和知识密集场景中的理解与生成。
6. CREMA: Generalizable and Efficient Video-Language Reasoning via Multimodal
Modular Fusion — ICLR 2025；多模态融合与视频推理。以模块化适配器融合多种视频衍生模
态，在少量可训练参数下提升视频语言推理。
7. CSA: Data-efficient Mapping of Unimodal Features to Multimodal Features — ICLR
2025；对齐与表征学习。用少量配对数据学习从单模态特征到多模态空间的映射，并讨论向 LiDAR
等模态扩展。

6. 研究选题建议与后续跟踪框架
6.1 建议的阅读顺序
1. 第一阶段：先读统一架构与对齐，理解多模态 Token、连接器、联合空间和训练目标。
2. 第二阶段：重点读缺失模态、模态冲突、表示解耦和模态平衡，这是多传感器系统最核心的实际
问题。
3. 第三阶段：转向视频、音频、3D 和具身模型，学习时序建模、空间关系与闭环决策。
4. 第四阶段：阅读评测与幻觉论文，为自己的研究设计可诊断实验，而非只报告平均准确率。
5. 第五阶段：结合无线数据特点，选择一个可验证的核心矛盾，例如动态模态选择、物理 Token、
开放类别或长时序压缩。
6.2 建议持续跟踪的关键词
 native multimodal model / unified multimodal tokenizer
 missing modality / modality conflict / modality imbalance
 omnimodal representation / any-to-any retrieval
 multimodal chain-of-thought / visual reasoning / spatial reasoning
 vision-language-action / multimodal agents / embodied foundation model
 sensor-language model / time-series language model / physical tokens
 dynamic token pruning / modality-aware sparse attention
 multimodal hallucination / uncertainty / evidence calibration
6.3 使用本清单时需要注意
“尽可能多”与“严格穷尽”并不等价。顶会论文数量极大，且部分论文虽使用图文数据，但核
心贡献并不属于多模态学习。本次清单采用高相关筛选，保证条目对理解多模态模型、融合机制、评
测或跨模态应用具有直接价值。对于具体研究方向，建议继续以论文引用链、官方代码和后续引用为
单位做二次深挖。
