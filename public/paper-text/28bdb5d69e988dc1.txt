AAAI 2026 的 6 个方法趋势
把 52 篇精选论文放在一起看，更值得关注的是这些可迁移的方法论变化。
01
SNN 从“替代 ANN”转向混合骨干与时延机制
重点不只是脉冲化，而是混合 SNN/ANN、TTFS、可学习时延、单
时间步传播与训练稳定性。
02
无线感知从同域分类转向“物理不变量 + 跨域”
WiFi/毫米波工作更强调 Doppler、JEPA、不变量表征、弱监督和
跨姿态/跨距离泛化。
03
Token 预算开始由任务与物理语义共同决定
动态语义 Token、Query-aware Token、层级压缩都在反对固定
均匀切分和无差别计算。
04
Agent / RAG 的核心变成记忆选择与通信效率
复杂 Agent 不再靠堆数量，而是关注 intent-driven memory、通
信剪枝、分层检索与长程任务协调。
05
世界模型与 VLA 更强调 grounding 与测试时适应
重建辅助任务、状态-动作统一预测和 test-time world model
training 让感知、预测、动作形成闭环。
06
时序建模开始显式引入物理、因果与分布漂移
Physics-aware sampling、channel-aware pretraining、TTA、
因果结构学习成为连续信号建模的重要抓手。

Spiking-Aided Neural Architecture for Efficient and Robust WiFi Sensing
AAAI-26 · SNN · WiFi · 鲁棒感知
论文概述 提出 SWS-Net，将脉冲神经网络的噪声鲁棒动态与传统 ANN 的特征提取能力结合，用于 WiFi 无设备室内感知。论文
还从理论上比较 SNN 与 ANN 的抗噪特性，并在三个 WiFi 感知任务上验证更高精度与更快收敛。
可借鉴点 直接可借鉴“无线信号 + SNN/ANN 混合骨干”的设计；尤其适合进一步研究多径、噪声和跨环境变化下的鲁棒
感知。

可借鉴点 适合借鉴“先找硬件/能耗约束中的隐藏非脉冲算子，再重构基础模块”的创新路径；也可作为无线 SNN

可借鉴点 可借鉴“把时间编码直接变成可优化的计算结构”，对低时延无线感知尤其有价值；也提示可从解码端而非只从

“搜索所有录用论文”的含
义
本报告把官方 48 个 issue 作为录用全集的索引边界，并对与你研究相关的 Track、关键词和交叉主题进行候选检
索，再逐篇核对官方摘要。正文不逐条列出全部四千余篇论文，而是输出筛选后的高价值集合。
为什么没有只按关键词筛 无线/多模态论文经常不会在标题里写 LLM、token、SNN；因此筛选同时看 Track、标题和摘要中的方法结构，例
如 test-time adaptation、representation alignment、dynamic tokenization、world model 等。
如何用这份报告 如果目标是尽快产出研究想法，优先精读 S 级论文：先复现/画结构图，再分别记录“问题、物理先验、token/表
示、训练目标、泛化设置、可替换模块”。之后再读 A 级论文寻找可组合模块。
一个可形成新课题的组合 “Physics-aware Dynamic Tokenization + SNN Heterogeneous Latency + Query-oriented Token Budget +
LLM/MLLM Alignment”：先依据无线物理变化自适应切 token，再用 SNN 进行稀疏时序编码，根据文本任务动态
保留关键 token，最后与语言空间对齐并生成长时动作描述。
